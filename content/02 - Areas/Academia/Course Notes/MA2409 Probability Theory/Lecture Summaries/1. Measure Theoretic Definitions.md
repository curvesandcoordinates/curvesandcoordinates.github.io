## Integration

We use Integration in probability theory as a jumping off point. When defining the lebesgue integration we introduce many concepts that become very useful in the context of probability theory.

The main thing that we look at is that the definition of a random Variable is simply a measurable function from some $\Omega$ into $\R$. Similarly when we define significant properties like Expectation and Variance of a random variable we can do so by integrating these measurable functions.

> [!definition] Expectation and Variance
> Given a probability space $(\Omega, \mathcal{F}, P)$ and a random variable $X: \Omega \to \R$ we define
>
> - The Expectation of $X$ by: $\Exp{X} = \int_{\Omega} X(\omega) dP(\omega) = \int_{\Omega} X dP = \left( \int_{0}^{\infty} P(X \geq t)dt\right)$
> - The Variance of $X$ by: $\var(X) = \Exp{(X- \Exp{X})^{2}}= \Exp{X^{2}} - \left[ \Exp{X} \right]^{2} \geq 0$

Some more complex language we will need sometimes is talking about how uniform $X$ is defined and how different variables might relate

> [!definition] k-th Moment
> Given a random variable $X$ we say it has $k$-th moment if $\Exp{|X|^{k}}< \infty$

> [!definition] Covariance of two Variables
> Given two random variables $X, Y$ that both have expectation, with the property that $XY$ also has expectation we define the covariance of the two variables as
> $\cov(X, Y) = \Exp{(X- \Exp{X})(Y - \Exp{Y})} = \Exp{XY} - \Exp{X} \Exp{Y}$

Note that a useful formula that we wont repeat or reprove is that of the connection between Variance and Covariance and looking at summations of variables.

> [!proposition] Vairance and Covariance Connection
> For one the variance is a special case of the covariance
> $\cov(X, X) = \var(X)$
> But also when considering a set of random variables $X_{i}$ with $i \in \set{1, \ldots, m}$ we get
> $\var\left(\sum\limits_{i=1}^{m} X_{i} \right)= \sum\limits_{i} \var(X_{i}) + \sum\limits_{i\neq j} \cov(X_{i}, X_{j})$
> Since given independent random variables we know that the covariance dissapears we can derive an important property of the variance with this
> $\var\left(\sum\limits_{i=1}^{m} X_{i} \right)= \sum\limits_{i} \var(X_{i})$

### Useful Theorems for Calculating Integrals

> [!theorem] Fatou
> If the functions $f_{k}$ are non-negative then
> $\int_{\Omega} \lim \inf f_{k} d \mu \leq \lim \inf \int_{\Omega} f_{k} d \mu$

> [!theorem] Monotone Convergence Theorem
> Given pointwise increasing functions $f_{k}$ such that $f_{k} \to f$ almost surely such that the $f_{k}$ are all non-negative, then
> $\int_{\Omega} f d \mu = \lim \int_{\Omega} f_{k} d \mu$

In our usees integral will mostly be computing in calculating the expectation of a variable, since this is simply the integral of the variable under the probability measure.

> [!corollary] Monotone Convergence for Expectations
> Given a sequence of non-negative random variables $X_{n}$ , then given $X_{n} \overset{a.s.}{\to} X$ then
> $\Exp{X} = \Exp{\lim X_{n}} = \lim \Exp{X_{n}}$

Similarly a general integral theorem is given by

> [!theorem] Dominated Convergence Theorem
> Given a sequence of functions $f_{k}$ which are dominated by a non-negative integrable function $g$, meaning for every $k$ we have $|f_{k}(x)| \leq g(x)$ we get that
> $\int_{\Omega} f d \mu = \lim \int_{\Omega} f_{k} d \mu$

Applying this to expectations give us the most useful property of expectations

> [!corollary] Dominated Convergence in Expectations
> Given a sequence of random variables $X_{n}$ with the property that there exists a non-negative $Y$ such that $\Exp{Y} < \infty$ and $|X_{n}| \leq Y$ almost surely we get that
> $\Exp{X} = \lim \Exp{X_{n}}$

## Distributions and Radon-Nikodym Theorem

Given a random Variable we can consider a probability measure induced by it on $\R$, by simply defining $D_{X} (A) = P(X^{-1}(A))$. By doing this we gain two things.

1. We can express the behaviour of $X$ in a function which we will call the distribution fundction defined by $F_{X}(a) = D_{X}( (- \infty, a]) = P(X \leq a)$
2. This measure might have a property called absolute continuity w.r.t the lebesgue measure and thus connects to $X$ a function called a density $f: \R \to \R$ with the property that for any $A$ we have $P(X \in A) = P(X^{-1}(A)) = D_{X}(A) = \int_{\R}f d \lambda$

### Radon-Nikodym

> [!definition] Absolute Continuity
>
> 1. We call a measure $\nu$ absolutely conitunous with respect to a measure $\mu$ if for every set $A \in \mathcal{F}$ $\mu(A) = 0 \implies \nu(A) = 0$ this is denoted by $\nu << \mu$
> 2. We say the $\nu$ and $\mu$ are equivalent (written $\mu \sim \nu$) if $\nu << \mu$ and $\mu << \nu$
> 3. We say that $\mu$ and $\nu$ are singular if there exists $A \in \mathcal{F}$ such that $\mu(A) = 0$ and $\nu(A^{c}) = 0$ we write this as $\mu \perp \nu$

> [!theorem] Radon-Nikodym
> Let $(\Omega, \mathcal{F})$ be a measurable space, and let $\mu$ and $\nu$ be a ${} \sigma$-finite measures on $(\Omega, \mathcal{F})$. Assume, in addition, that $\nu << \mu$. Then there exists a measurable and non-negative function $f: \Omega \to \R$ such that for every $A \in \mathcal{F}$,
> $\nu(A) = \int_{A}f d \mu$

When using this theorem we will often want to write down the measures in a very imprecice way. Namely we will write the radon-nikodym derivative as $f = \frac{d\nu}{d\mu}$ even further we will often write something like $d \nu = g d \mu$.

Often we have two measures that result from distributions. Most distributions we know will be absolutely continuous wrt $\lambda$ meaning we can write
