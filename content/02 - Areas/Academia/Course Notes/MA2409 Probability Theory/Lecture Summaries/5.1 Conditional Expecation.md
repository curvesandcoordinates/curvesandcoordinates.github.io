# Conditional Expectaiton

## Our old Definitions

From EWS we know how to answer the question of conditioning probability on an Event.

> [!definition] Conditional Probability and Expectation
> Given a Random Variable $X$ and and two Events $A, B$ with $P(B) \neq 0$ we define the conditional probability and conditional expectation as follows
> $P(A \mid B) = \frac{P(A \cap B)}{P(B)}$
> and
> $\Exp{X \midline B} = \frac{\Exp{X \cdot \mathbb{1}_{B}}}{P(B)}$

### The Problem

The introductory example of conditional expectation is considering the space $([0,1]^{2}, \mathcal{B}([0,1]^{2}), \lambda)$ and $X: [0,1]^{2} \to \R$ bounded and let $Z(x, y) = x$ and $W(x, y) = y$ is it now possible to know something about $\Exp{X \midline Z = \frac{1}{4}}$
Not really right? Since $\lambda\left(Z = \frac{1}{4}\right)= 0$  so formally we wont be able to calculate it. Eventhough we should be able to calculate it explictily by considering
$\Exp{X \midline Z = \frac{1}{4}} = \int_{0}^{1} X \left( \frac{1}{4}, y \right) dy$
This means that there is a way to think of this conditional expectation, were just not sure how. The generalization will make precice a random variable $\Exp{X \midline Z}: Z(\Omega) \to \R, \quad t \mapsto \Exp{X \midline Z = t}$

## The New Definition

> [!definition] Conditional Expectation
> Given a random variable $X$ with expectation let $\mathcal{G} \subset \mathcal{F}$ be a $\sigma$-algebra on $\Omega$. We call a random variable $Y$ the **conditional expectation of $X$ with respect to $\mathcal{G}$** and write $Y = \Exp{X \midline \mathcal{G}}$ if:
>
> 1. $Y$ is measurables with respect to $\mathcal{G}$
> 2. For any bounded $Z$ which is measurable with respect to $\mathcal{G}$ we have $\Exp{ZY} = \Exp{ZX}$

> [!remark] Interpretation of the Defining Proeprty of Conditional Expectation
> Note that importantly the second property can be read as $Y$ agreeing on avarage with $X$ on any set $A \in \mathcal{G}$. This can be seen if you pick $Z = \mathbb{1}_A$ then this is only $\mathcal{G}$ measurable if $A \in \mathcal{G}$. Given this we see that
> $P(Y \mid A) \cdot P(A)= \Exp{\mathbb{1}_{A}\cdot Y} = \Exp{\mathbb{1}_{A} X} = P(X \mid A) \cdot P(A)$
> which gives us
> $P(Y \mid A) = P(X \mid A)$
> thus we get that $Y$ is in a sense a good approximation of $X$ on all events occuring in $\mathcal{G}$

The Uniquness and Existence of the conditional Expectation as defined above is easily proven using the defining property and some elbow grease. But we won’t do that here.

A thing to note is that we can also define for two random Variables $X, Y$ the conditional expectation $\Exp{X \midline Y}$ to be $\Exp{X \midline \sigma(Y)}$

The important properties we from this conditional expectation to actuall work with it are given in the following Lemma

> [!lemma] Properties of Conditional Expectaion
>
> 1. For the trivial $\sigma$-algebra $\mathcal{G} = \set{ \emptyset, \Omega}$ we get $\Exp{X \midline \mathcal{G}} = \Exp{X}$
> 2. Given $\mathcal{G}$ is independent of $X$ we get $\Exp{X \midline \mathcal{G}} = \Exp{X}$ almost surely
> 3. Given an includion of $\sigma$-algebras: $\mathcal{G}_{2} \subset \mathcal{G}_{1} \subset \mathcal{F}$ we get the equality $\Exp{\Exp{X \midline \mathcal{G}_{1}} \midline \mathcal{G}_{2}} = \Exp{X \midline \mathcal{G}_{2}}$
> 4. Jensen’s Innequality: For a convex function $f$ we get $f(\Exp{X \midline \mathcal{G}}) \leq \Exp{f(X) \midline \mathcal{G}}$
> 5. We can define a conditional variance $\var(X \mid \mathcal{G}) := \Exp{ \left( X - \Exp{X \midline \mathcal{G}} \right)^{2} \midline \mathcal{G}} = \Exp{X^{2} \midline \mathcal{G}} - \left( \Exp{X \midline \mathcal{G}} \right)^{2}$ and we also have the property that if $\var(X) < \infty$ then $\var(X) = \Exp{\var(X \mid \mathcal{G}) + \var \left( \Exp{X \midline \mathcal{G}} \right)}$
> 6. Given a $W$ that is measurable w.r.t $\mathcal{G}$ and $\Exp{\left| XW \right|} < \infty$ then we get that $\Exp{WX \midline \mathcal{G}} = W \Exp{X \midline \mathcal{G}}$
> 7. Linearity holds for conditional Expectation: $\Exp{X + Y \midline \mathcal{G}} = \Exp{X \midline \mathcal{G}} + \Exp{Y \midline \mathcal{G}}$

### A Useful interpretation

Given the important of sigma subalgebras in the definition of conditional expectation we know that we can interpret them in a different light using this knowleadge. For a probablist you consider the sigma algebra as a measure of how much knowleadge you have at any given point.
In the real world we often want to predict $X$ given some data, meaning we would like to approximate it somehow using the limited data we have and see what this approximation predicts about the real $X$. Given no data a good estimate or predictor is given by the avarage value or more precicely the expected value of $X$ this maps on to the fact that
$\Exp{X} = \Exp{X \midline \set{\emptyset, \Omega}}$
Now in the concrete example given at the beginning of this chapter we define can define say $X: [0,1]^{2} \to \R$ and two maps $P_{1}: (x, y) \mapsto x$ and $P_{2}: (x, y) \mapsto y$. Now given information on how $X$ acts on the vertical strips for example, meaning we consider the values
$\forall t: \quad \Exp{X \midline P_{1} = t} \in \R$
We should be able to approximate for a given $(x, y)$ what $X$ would output using this data. This approximator would be
$\tilde X: (x, y) \mapsto \Exp{X \midline P_{1} = x}$
This is now a new random variable which as we have discussed before is not formally calculable but it caputres the Idea. We would consider the random variable properly defined as
$\tilde X = \Exp{X \midline P_{1}}$
which is the best approximator in this case.
