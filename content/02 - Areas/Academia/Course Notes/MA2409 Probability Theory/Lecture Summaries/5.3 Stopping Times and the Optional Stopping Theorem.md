# Stopping Times

> [!definition] Stopping Times
> Given a filtration $\mathcal{G_{n}}$ a random variable $T: \Omega \to \N \cup \set{\infty}$ is called a stopping time if for every $n$ we have
> $\set{T \leq n} \in \mathcal{G_{n}}$

The connection between stopping times and martingale is the construction of a stopped martingale like in the following Lemma

> [!lemma] Stopped Martingale
> Given a filtration $\set{\mathcal{G_{n}}}$ let $\set{X_{n}}$ be a martingale with respect to $\set{\mathcal{G_{n}}}$ and let $T$ be a stopping time with respect to $\set{\mathcal{G_{n}}}$. We define a stopped martingale by
> $Y_{n} = X_{n \land T} = X_{\min\set{n, T}}$
> Then we have that
>
> 1. $\set{Y_{n}}$ is a martingale
> 2. If there exists a random variable $X$ such that $\Exp{|X|}< \infty$ and $|Y_{n}| \leq X$ a.s. for all $n$ and if $1 \leq T < \infty$ a.s. then $\Exp{X_{T}} = \Exp{X_{1}}$

`\begin{proof}`

1. Use the expression $Y_{n} = \left( \sum\limits_{k=1}^{n-1} Y_{n} \mathbb{1}_{\set{T = k}}  \right) + Y_{n} \mathbb{1}_{\set{T \geq n}} = \left( \sum\limits_{k=1}^{n-1} X_{k} \mathbb{1}_{\set{T = k}}  \right) + X_{T} \mathbb{1}_{\set{T \geq n}}$
2. Since $T < \infty$ we have that $Y_{n} \to X_T$ a.s. and by dominated convergence get that $\Exp{X_{T}} = E(X_{1})$
   `\end{proof}`

This is a nice precursor to the big theorem for stopping times which is the optimal stopping theorem. It extends to more general conditions

> [!theorem] Optional Sampling Theorem
> Let $\mathcal{G}_{n}$ be a filtration and $X_{n}$ be a martingale with respect to $\mathcal{G}_{n}$ and let $T$ be a stopping time with respect to $\mathcal{G}_{n}$. Then given one of the following conditions we get $\Exp{X_{T}} = \Exp{X_{1}}$
>
> 1. $T$ is bounded meaning $\exists M: P(T < M) = 1$
> 2. $X_{n}$ is bounded and $T$ is finite
> 3. Given $\Delta X_{n} = X_{n+1} - X_{n}$we have $\Exp{|\Delta X_{n}| \midline \mathcal{G}_{n}}$ is bounded and $\Exp{T} < \infty$

`\begin{proof}`
Using the previous Lemma in every case we only have to define some random variable $X$ with expectation such taht $\forall n \in \N: |Y_{n}| \leq X\quad a.s$

1. Given $M$ as the bound of $T$ we define $X = \sum\limits_{k=1}^{M} |X_{k}|$
2. Take $X = M$ the bound of $X_{n}$
3. Take $M$ as the uniform bound of $\Exp{|\Delta X_{n}| \midline \mathcal{G}_{n}}$ and define $X = X_{1} + \sum\limits_{k=2}^{T} \Delta X_{k-1}$
   `\end{proof}`

We can also state this for submartingales in the following way

> [!theorem] Optimal Stopping for Submartingales
> Let $\mathcal{G}_{n}$ be a filtration and $X_{n}$ be a sub-martingale with respect to $\mathcal{G}_{n}$ and let $T$ be a stopping time with respect to $\mathcal{G}_{n}$. Then given one of the following conditions we get $\Exp{X_{T}} \geq \Exp{X_{1}}$
>
> 1. $T$ is bounded meaning $\exists M: P(T < M) = 1$
> 2. $X_{n}$ is bounded and $T$ is finite
> 3. Given $\Delta X_{n} = X_{n+1} - X_{n}$we have $\Exp{|\Delta X_{n}| \midline \mathcal{G}_{n}}$ is bounded and $\Exp{T} < \infty$
