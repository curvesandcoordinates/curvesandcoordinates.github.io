# The Law of Large Numbers

We will want to talk about avarages of identically distributed random variables and formulate the law of large numbers.

The weak version is a rather simple statement

> [!theorem] Weak Law of Large Numbers
> Given $X_{k}$ a sequnce of i.i.d. variables expectation $E = \Exp{X_{k}}$ and finite variance $\sigma^{2} = \var(X_{k})$. Then we have
> $\frac{1}{n} \sum\limits_{k=1}^{n} X_{k} \overset{\text{prob}}{\to} E$

`\begin{proof}`
The proof of the weak law is rather simple by simply using chebischev. Defining a variable we get that for $S_{n} = \frac{1}{n} \sum\limits_{k=1}^{n} X_{k}$ we have
$\Exp{S_{n}} = \frac{1}{n} \sum\limits \Exp{X_{k}} = \frac{1}{n} n E = E$
and
$\var(S_{n}) = \frac{1}{n^{2}} \sum\limits \var{X_{k}} = \sigma^{2}/n$
Then chebishev gives us that
$P(|S_{n} - E| > \delta) = P(|S_{n} - \Exp{S_{n}}| > \delta) \leq \frac{\var(S_{n})}{\delta^{2}} = \frac{\sigma^{2}}{n \delta^{2}}$
Thus we get that
$P(|S_{n} - E| > \delta) \leq \frac{1}{n} \left( \frac{\sigma}{\delta} \right)^{2}\overset{n \to \infty}{\to} 0$
meaning $S_{n} \overset{prob}{\to} E$
`\end{proof}`

The strong law of large numbers is a little bit more convoluted to prove at first. We want to make the convence be almost sure.

> [!theorem] Strong Law of Large Numbers
> Given $X_{k}$ a sequnce of i.i.d. variables expectation $E = \Exp{X_{k}} < \infty$. Then we have
> $\frac{1}{n} \sum\limits_{k=1}^{n} X_{k} \overset{\text{a.s.}}{\to} E$

`\begin{proof}`
We first begin by defining our random variables
$Z_{n} = \frac{1}{n} \sum\limits_{k=1}^{n} X_{k}$
Then we can see that $Z_{n}$ is an inverse martingale since all properties of being one are fullfilled

1. Since $\Exp{|Z_{n}|} \leq \frac{1}{n} \sum\limits \Exp{|X_{k}|} = \Exp{X_{1}} < \infty$
2. $Z_{n}$ is obviously measurable with respect to $\mathcal{F}_{n} = \sigma(Z_{n}, Z_{n+1}, \ldots)$

Showing that $Z_{n} = \Exp{Z_{n-1} \midline \mathcal{F_{n}}}$ is a little bit more involved. Firstly we define a permutated set of variables. Given a number $m \in \N$ and some perumation $\eta \in S_{m}$
$X'_{k} = \begin{cases}X_{k} \quad& k > m \\ X_{\eta(k)}, \quad& k \leq m\end{cases}$
we also define the permuted sum by
$Z'_{n} = \frac{1}{n} \sum\limits_{k=1}^{n} X'_{k}$
Then note that importantly for $k \geq m$ we get that $Z'_{k} = Z_{k}$
With this we can see that the two tuples
$(X_{1}, X_{2}, \ldots, X_{m}, Z_{m}, Z_{m+1}, \ldots) \quad (X'_{1}, X'_{2}, \ldots, X'_{m}, Z_{m}, Z_{m+1}, \ldots)$
have the same joint distribution. Meaning that for any $W$ that is bounded and measurable with respect to $\sigma(Z_{m}, Z_{m+1}, \ldots)$, we have that
$\Exp{W X_{m}} = \Exp{W X'_{m}}$
meaning that by the property of conditional expectation that $\Exp{X_{m} \midline \mathcal{G_{m}}} = \Exp{X'_{m} \midline \mathcal{G_{m}}} = \Exp{X_{\eta(m)}\midline \mathcal{G_{m}}}$ and since $\eta$ is arbitrary we get that
$\Exp{X_{1} \midline \mathcal{G_{m}}} = \Exp{X_{2} \midline \mathcal{G_{m}}} = \cdots = \Exp{X_{m} \midline \mathcal{G_{m}}}$
Given this we can now finally calculate that
$Z_{m} = \Exp{Z_{m} \midline \mathcal{G_{m}}} = \Exp{\frac{1}{m} \sum\limits_{k=1}^{m} X_{k} \midline \mathcal{G_{m}}} = \frac{1}{m} \sum\limits_{k=1}^{m} \Exp{X_{k} \midline \mathcal{G_{m}}} = \Exp{X_{m} \midline \mathcal{G_{m}}}$
Using the fact that
$Z_{m-1} = \frac{1}{m-1} \sum\limits_{k=1}^{m-1} X_{k} = \frac{m Z_{m} - X_{m}}{m-1}$
we can calculate that
$\Exp{Z_{m-1} \midline \mathcal{G_{m}}} = \Exp{\frac{m Z_{m} - X_{m}}{m-1} \midline \mathcal{G_{m}}} = \frac{1}{m-1} \left( m \Exp{Z_{m} \midline \mathcal{G_{m}}} - \Exp{X_{m} \midline \mathcal{G_{m}}} \right) = \frac{m Z_{m} - Z_{m}}{m-1} = Z_{m}$
meaning $Z_{n}$ is an inverse martingale.

Given that inverse martingales convergese almost surely and inverse martingales are uniformly integrable we know that it must converge in $L^{1}$ to some variable $Z$ and by kolmogorov for a given $c \in \R$ the event
$A_{c} = \set{Z = c}$
is a tail event and thus has probability $0$ or $1$. This gives us that $Z$ must be an almost sure constant and given that $\Exp{Z_{n}} = \Exp{X_{1}} =: E$ we know that $Z = E$ almost surely.

Since $Z_{n}$ converges almost surely it must also converge almost surely to $E$ giving us what we wanted.
`\end{proof}`

> [!info]- Proof under Assumtion of Variance
> Write $\sigma^{2} = \var(X_{1})$ then its easy to see that using the definition of
> $S_{n}= \frac{1}{n} \sum\limits_{k=1 }^{n} X_{k}$
> it remains easy to prove that the subsequence $S_{n^{2}} = \frac{1}{n^{2}} \sum\limits_{k=1}^{n^{2}} X_{k}$ converges almost surely, since Chebbyshev applies and we have
> $\var(S_{n^{2}}) = n^{2} \sigma^{2} \quad \Exp{S_{n^{2}}} = E$
> giving us
> $P \left( |S_{n^{2}} - E | \geq \epsilon \right) \leq \frac{\var(S_{n^{2}})}{\epsilon^{2}} = \frac{\sigma^{2}}{\epsilon^{2}} \frac{1}{n^{2}}$
> Considering the sum
> $\sum\limits_{n} P \left( |S_{n^{2}} - E | \geq \epsilon \right) \leq \frac{\sigma^{2}}{\epsilon^{2}} \sum\limits_{n} \frac{1}{n^{2}} < \infty$
> meaning by Borel-Cantelli the event that $S_{n^{2}}$ deviates from $E$ by more than $\epsilon$ doesn’t happen infinitely often. This means there exists for every $\epsilon$ some $N_\epsilon$ such that for any $n > N_\epsilon$ we have that
> $|S_{n^{2}} - E| < \epsilon$
> Since this holds for any $\epsilon$ we have proven that for any $\omega$:  $\lim_{n} S_{n^{2}}(\omega) = E$ thus giving us
> $S_{n^{2}} \overset{a.s.}{\to} E$
> The idea to generalize this to the sequence $S_{n}$ comes from wanting to show the same result, meaning given some $\epsilon$ find some $N_\epsilon$ such that for any $n > N_\epsilon$ we have that $|S_{n} - E| < \epsilon$ but adding $0$ in the following way
> $|S_{n} - E| = |S_{n} - S_{n^{2}} + S_{n^{2}} - E| \leq |S_{n} - S_{n^{2}}| + |S_{n^{2}} - E|$
> The right sum is already known and the left will be shown to be less than $\epsilon$ too.
> To this end define for any $\epsilon  0$ (rational) and any $n$ the variable
> $U_{n} = \max_{n^{2} < k \leq (n+1)^{2}} |S_{k} - S_{n^2}|$
> the greatest deviation between $n^{2}$ and $(n+1)^{2}$. For ease of writing we write for a given $k \in (n^{2}, (n+1)^{2}] \cap \Z$
> $J_{k}= S_{k} - S_{n^2}$
> then we can use the same strategy as before using chebyshev to estimate $P(|J_{k}| > \epsilon)$.
> Note first that
> $J_{k} = S_{k} - S_{n^{2}}= \frac{1}{k} \sum\limits_{j = 1}^{k} X_{j} - \frac{1}{n^{2}} \sum\limits_{j = 1}^{n^{2}} X_{j}= \frac{1}{k} \sum\limits_{j = n^{2}}^{k} X_{j} + \frac{1}{k} \sum\limits_{j = 1}^{n^{2}} X_{j} - \frac{1}{n^{2}} \sum\limits_{j = 1}^{n^{2}} X_{j} = \frac{1}{k} \sum\limits_{j=n^{2}}^{k} X_{j} - \left( \frac{1}{n^{2}}- \frac{1}{k} \right) \sum\limits_{j=1}^{n^{2}}X_{j}$
> this gives us
> $\Exp{J_{k}} = \frac{1}{k} \sum\limits_{j=n^{2}}^{k} E - \left( \frac{1}{n^{2}}- \frac{1}{k} \right) \sum\limits_{j=1}^{n^{2}}E = \frac{k-n^{2}}{k}E - n^{2} \left( \frac{1}{n^{2}}- \frac{1}{k} \right) E = E \left( \frac{k-n^{2}}{k} + \frac{n^{2}}{k} - 1 \right) = 0$
> and
> $\var(J_{k}) = \frac{k-n^{2}}{k} \sigma^{2} + \left( \frac{1}{n^{2}}- \frac{1}{k} \right)^{2} n^{2} \sigma^{2} = \sigma^{2} \left( \frac{k-n^{2}}{k} -  \frac{(k-n^{2})^{2}}{kn^{2}}n^{2} \right) \leq \frac{4\sigma^{2}}{n^{3}}$
> Thus by Chebisheff
> $P(|J_{k}| > \epsilon) = P(|J_{k} - \Exp{J_{k}}| > \frac{\epsilon}{2}) \leq \frac{4 \var(J_{k})}{\epsilon^{2}} \leq \frac{C_{1}}{n^{3}}$
> This means for us that
> $P(U_{n} \geq \epsilon) \leq \left( (n+1)^{2} - n^{2} \right) \frac{C_{1}}{n^{3}} \leq \frac{C_{2}}{n^{2}}$
> Thus by Borel Cantelli we can argue that $U_{n}$ only eceeds epsilon for finitely many $n$ meaning for $n$ big enough we have that $|S_{n} - S_{n^{2}}|<\epsilon$.

We can also prove a nice converse of the Law of large numbers given by

> [!theorem] Converse of LLN
> Given $X_{n}$ a sequence of i.i.d random variables and setting $S_{n} = \sum\limits X_{j}$ then we can prove that
> $\exists X: \frac{S_{n}}{n} \overset{a.s.}{\to} X \implies X=\Exp{X_{1}} \text{ a.s.}$

`\begin{proof}`
Due to the Law of Large numbers we know this statement to be true if $\Exp{|X_{1}|} < \infty$. Meaning we can assume for contradiction that $\Exp{|X_{1}|} = \infty$ while also $\frac{S_{n}}{m} \overset{a.s.}{\to} X$. We then know that:
$\sum\limits_{k=1}^{\infty} P(|X_{1}| \geq k) = (-1) + \sum\limits_{k=0}^{\infty} P(|X_{1}| \geq k) \geq \Exp{|X_{1}|} - 1 \geq \infty$
Now note that we can change the sum since the $X_{i}$ are all identically distributed to
$\sum\limits_{k=1}^{\infty} P(|X_{k}| \geq k) = \sum\limits_{k=1}^{\infty} P(|X_{1}| \geq k) = \infty$
Since now the events $A_{k} = \set{|X_{k}| \geq k}$ are all independent we can apply Borel cantelli II and see that $P(|X_{k}| \geq k \text{ infinitely often}) = 1 \implies \exists \set{n_{k}}_{k}: |X_{n_{k}} \geq n_{k}$
Using this subsequence we will now apply the convergence assumtion and note that almost sure convergence gives us the validiy of a cauchy criterion so consider
$\frac{S_{n_{k}}}{n_{k}} - \frac{S_{n_{k}-1}}{n_{k}-1} = \frac{S_{n_{k}-1} + X_{n_{k}}}{n_{k}} - \frac{S_{n_{k}-1}}{n_{k}-1} = \frac{X_{n_{k}}}{n_{k}} + \left( \frac{n_{k}-1}{n_{k}}-1 \right) = \frac{X_{n_{k}}}{n_{k}}- \frac{1}{n_{k}}\frac{S_{n_{k}-1}}{n_{k}-1}$
Then we know that by the cauchy criterion we have
$0 = \lim \left( \frac{S_{n_{k}}}{n_{k}} - \frac{S_{n_{k}-1}}{n_{k}-1}  \right) = \lim \left( \frac{X_{n_{k}}}{n_{k}}- \frac{1}{n_{k}}\frac{S_{n_{k}-1}}{n_{k}-1} \right)$
but since we have assumed convergence we also have that
$\lim \frac{1}{n_{k}}\frac{S_{n_{k}-1}}{n_{k}-1} = 0$
and since we have chose $n_{k}$ in a specific way we also get
$\lim \inf \left| \frac{X_{n_{k}}}{n_{k}} \right| \geq 1$
but this means that the limit in the cauchy criterion can never be $0$ which is a contradiction.
`\end{proof}`
