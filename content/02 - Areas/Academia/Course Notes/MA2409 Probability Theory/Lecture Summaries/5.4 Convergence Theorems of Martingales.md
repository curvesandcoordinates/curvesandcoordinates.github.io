# Convergence Theorems

We will want to find conditions under which we have that a given martingale converges almost surely. The strategy in general is to prove this for positive martingales, then for positive sub-martingales and then simply split $X_{n} = X_{n}^{+} - X_{n}^{-}$

We first need this Lemma

> [!lemma]
> Given a positive sub-martingale $X_{n}$ with the property that
> $\sup \set{\Exp{X_{n}} \midline n \in \N} < \infty$
> then $P(\sup_{n} X_{n} < \infty ) = 1$

`\begin{proof}`
Our main strategy here is to show for $S = \sup \set{\Exp{X_{n}} \midline n \in 1, 2, \ldots}$ that $\lim_{k\to \infty} P ( \sup_{n} X_{n} > k) = 0$
To show this we fix a $k$ and define $T = \inf \set{n \midline X_{n} > k} \leq \infty$. Using the submartingale property we let $j > i$ be some numbers and note that
$\Exp{X_{j} \midline T = i} > k $
The events $\left( \set{T = i} \right)i \in N$ are disjoint we know that
$\Exp{X_{j} \midline T < j} > k$
and using markov we get that
$P (T < j) \leq \frac{\Exp{X_{j}}}{\Exp{X_{j} \midline T < j}} < \frac{\Exp{X_{j}}}{k} < \frac{S}{k}$
since this is true for any $j$ we know that $P(T < \infty) < P ( \cup_{j} \set{T \leq j}) = \lim_{j \to \infty} P(T < j) <\frac{S}{k} \to 0$ and thus
$0 = P(T< \infty) = P(\sup X_{n} > k) \implies P(\sup X_{n} < \infty) = 1$
`\end{proof}`

# Uniform Integrability and $L^{1}$ Convergence

We now want to caputre when a Martingale would converge in $L^{1}$ to some random variable. This leads us to the idea of uniform integrability which is a technical property of the distribution of a sequence of random variable

> [!definition] Uniformly Integrable
> Let $X_{n}$ be a sequence of random variables. We call $X_{n}$ uniformly integrable if for any $\epsilon > 0$ there exists $M$ such that for any $n$
> $\Exp{|X_{n}| \cdot \mathbb{1}_{|X_{n}| > M}} < \epsilon$

Our main source for uniformly integrable sequences will be from martingales. Speicifically given by this Lemma

> [!lemma] Construction of Uniformly Integrable Variables
> Let $X$ be a random variable and $\mathcal{G_{n}}$ be a sequence of $\sigma$-algebras. Then define the sequence $X_{n}$ by $X_{n}= \Exp{X \midline \mathcal{G_{n}}}$then $X_{n}$ is uniformly integrable

The most important corolarry here is that thus **all inverse martingales are actually uniformly integrable**.

> [!theorem] Uniform + A.S. Convergence means $L^1$
> Let $X_{n}$ be a uniformly integrable sequence of random variables with the property that $X_{n}$ converges almost surely to some $X$ then
> $X_{n} \overset{L^{1}}{\to} X$

This is very useful if coupled with martingale convergence theorems since we can no use convergence and uniform integrability to prove $L^{1}$ convergence. Specifically its useful for proving the law of large numbers.

We can specifically state the previous results for martingales and combine them to finally this theorem

> [!theorem] Uniformly Integrable Martingales
> Given a martingale $X_{n}$ with respect to the filtration $\mathcal{G_{n}}$ we can state that
> $X_{n}\text{ is uniformly integrable} \iff \exists X \forall n \in \N: X_{n}= \Exp{X \midline \mathcal{G_{n}}}$
