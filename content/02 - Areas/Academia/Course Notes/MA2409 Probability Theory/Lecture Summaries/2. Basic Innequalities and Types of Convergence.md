# Basic Innequalities and Types of Convergence

## Innequalities

- **Cauchy-Schwarz**: Given $X, Y$ RVs with second moments we get: $\Exp{XY}^{2} \leq \Exp{|XY|}^{2} \leq \Exp{X^{2}} \Exp{Y^{2}}$
- **Markov**: Given $X$ non-negative and $a > 0$ we have $P(X \geq a) \leq \frac{\Exp{X}}{a}$
- **Jensen**: Given a convex function $f: \R \to \R$ and $X$ a RV such that $X$ and $f(X)$ have expectation then $f(\Exp{X}) \leq \Exp{f(X)}$
  - This is the reason the variance is always positive
- **Chebisheff**: Given $X$ with variance and some $\delta > 0$ we get $P(\left| X - \Exp{X} \right| \geq \delta) \leq \frac{\var[X]}{\delta^{2}}$
- **Payley-Zygmund**: Given $X$ non-negative with second moment. We then have $P(X > 0) \geq \frac{\left( \Exp{X} \right)^2}{\Exp{X^{2}}}$
  - Can be read better by considering that the complement event is simply $X = 0$.

## Tail Events

### Borel-Cantelli

We want to now handle staments about some event occuring infinitely often given a sequence of events. This means we want to be given a sequence of events $(A_{k})_{k \in \N}$ and want to use them to know about $A = \lim \sup A_{k}$ which corresponds to the intuition that the $A_{k}$ occur infinitely often.

> [!theorem] Borel Cantelli Lemma
> Given a sequence of events $(A_{k})_{k \in \N}$ and their limit $A = \lim \sup A_{k}$ we get that
>
> 1. If $\sum\limits_{k=1}^{\infty} P(A_{k}) < \infty$ then $P(A) = 0$ meaning that $P(A_{k} \text{ occur infinitely often }) = 0$ which implies $P(A_{k} \text{ occur a finite number of times}) = 1$
> 2. If all $A_{k}$ are intependent and $\sum\limits_{k=1}^{\infty} P(A_{k}) = \infty$ then $P(A) = 1$

`\begin{proof}`

1. Proof idea for 1 is to consider that $A = \lim \sup A_{k} = \bigcap \bigcup A_{k}$ thus $A \subset \bigcap_{j=k}^{\infty} A_{j}$ and then going into probabilites.
2. The idea here is that we define $B_{k} = \bigcup_{j=k} A_{j}$ and calculate $P(B_{k}^{c}) = 0$ and using the continuity of probability and of the exponential function and the fact that $\log x \leq x - 1$ we get the result after some computation using that $P(A) = \lim P(B_{k}) = 1$

`\end{proof}`

## Types of Convergcen

Definitions

- Probability:
  - Definition: $\forall \delta > 0: \lim_{k \to \infty} P(|X - X_{k}| > \delta) = 0$
  - Alternative Definition:  $\forall \epsilon > 0 \exists N \forall n > N: P(|X-X_{n}| > \epsilon) < \epsilon$
- Almost Sure:
  - Definition: $P \left( \set{\omega \midline \lim X_{n}(\omega) = X(\omega)} \right) = 1$
  - Alternative Definition: $\forall \epsilon > 0 \exists N: P \left( \exists n > N: |X - X_{n}| > \epsilon \right) < \epsilon$
- Lp:
  - Definition: ${} \lim_{n \to \infty} \Exp{|X - X-n|^{p}} = 0 {}$
  - Interesting Property: $a < b \implies \left( X_{k} \overset{L^{b}}{\to} X \implies X_{k} \overset{L^{a}}{\to} X \right)$
- Distribution:
  - Definition: For any bounded continuous $f$ with compact support we want $\lim_{n \to \infty} \Exp{f(X_{n})} = \Exp{f(X)}$
  - Alternative Definition: Given the distribution functions we want $\lim_{n \to \infty} F_{X_{n}}(x) = F_{X}(x)$

Relations:
The most basic relationship is given by the three diagrams

- $\text{almos sure} \implies \text{probability}$
- $L^{p} \implies \text{probability}$
- $\text{probability} \implies \text{distribution}$

Sometimes we do use though that the backwards implications can hold given assumptions

- Given $X_{n} \overset{\text{prob}}{\to} X$ there exists strictly increasing sequence $\set{n_{k}}$ such that $X_{n_{k}} \overset{\text{a.s.}}{\to} X$
- Given $X_{n}$ converges to $X$ in distribution and $X = c \in \R \text{ a.s.}$ we get $X_{n} \overset{\text{prob}}{\to} X$
