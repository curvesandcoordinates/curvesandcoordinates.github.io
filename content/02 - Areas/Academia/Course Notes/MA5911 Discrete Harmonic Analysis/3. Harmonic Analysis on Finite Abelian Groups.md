Harmonic Analysis deals with transforming functions into a so-called frequency space. This means that in a certain sense the model we are trying to get to takes a map
$f: G \to \C \implies \hat f: \widehat{G} \to \C$
Where now $\widehat{f}$ takes in [[Group Characters]] which represent vibration modes and gives out a complex number $\widehat{f}(\chi)$ which contains information how much $f$ contains this vibration mode. Specifically we should decompose
$\widehat{f}(\chi) = re^{it}$
where
$r = \text{how much does }f \text{ vibrate} \quad t = \text{with what phase does } f \text{ vibrate}$

To get to this we could simply define the [[Discrete Fourier Transform|discrete fourier transform (DFT)]] of a given function $f$. In order to be able to see the similarities to continous harmonic analysis we will take a slight detour first defining an algebra of linear functionals on our group called the [[The Group Algebra| group algebra]] which in our case is isomorphic to the [[Group Characters#^8a3d23|dual group]]. Formally we then define the gelfand representation which is a way to map from the group algebra to [[The Group Algebra#^f76246|its spectrum]] which formally is exactly the transformation of a map to its fourier transform. We can then find some properties of the now formally founded [[Discrete Fourier Transform| DFT]]  and then discuss some informational relationship between $f$ and $\widehat{f}$ limited by cetrain [[Discrete Uncertainty Principles|uncertainty principles]].
