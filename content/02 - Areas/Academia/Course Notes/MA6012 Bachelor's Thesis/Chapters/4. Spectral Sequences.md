## Serre-Spectral Sequence for $SU(n)$

Now we have all the theory laid out, we can use the Serre spectral sequence to determine via induction the Betti numbers of $SU(n)$, which turn out to be given by the Poincaré polynomial
$P_{SU(n)}(t) = (1+t^{3})(1+t^{5})\ldots (1+t^{2n-1})$

### Cohomology of $SU(3)$

To motivate this, we will work through the calculation for $SU(3)$. Note that, given our previous calculations, $SU(2) \cong S^{3}$ and thus $SU(3)$ is a $S^{3}$ bundle over $S^{5}$ given by the diagram:
![[04 - Resources/Assets/Mapping Diagram SU(3) MA6012.png| center | 200]]

To apply the Serre spectral sequence we will use the well-proven fact from homotopy theory, that $S^n$ is simply connected and has finite dimensional cohomology groups (as we have calculated before), which gives an $E_2$ page
$E_2^{p,q} = H^p(S^5) \otimes H^q(S^3)$
Given the fact that
$H^{q}(S^{3}) = \begin{cases} \R \quad q = 0 3 \\ 0 \quad \text{otherwise}\end{cases}$
and also
$H^{p}(S^{5}) = \begin{cases} \R \quad q = 0 5 \\ 0 \quad \text{otherwise}\end{cases}$
we can easily see that the only non-trivial elements of our $E_2$ page
are

$$$\begin{aligned}
    &E_{2}^{0,0} = H^0(S^5) \otimes H^0(S^3) \cong \R \otimes \R \cong \R \\
    &E_{2}^{0,3} = H^0(S^5) \otimes H^3(S^3) \cong \R \otimes \R \cong \R \\
    &E_{2}^{5,0} = H^5(S^5) \otimes H^0(S^3) \cong \R \otimes \R \cong \R \\
    &E_{2}^{5,3} = H^5(S^5) \otimes H^3(S^3) \cong \R \otimes \R \cong \R
\end{aligned}$$
meaning the $E_{2}$ page has the following Form:
![[04 - Resources/Assets/E2 Page of SU(3) MA6012.png| center | 450]]
We are now concerned with determining what this sequence converges to. We can observe that all the differentials can be categorised by their codomain 
$$d_2^{p,q}: E_2^{p,q} \to E_2^{p + 2, q - 1} = 
    \begin{cases} 
        d_2^{p,q}: \R \to \set{0} \quad p \in \set{0, 5}, q \in \set{0,3}\\
        d_2^{p,q}: \set{0} \to \R \quad p \in \set{-2, 3}, q \in \set{1, 4}\\
        d_2^{p,q}: \set{0} \to \set{0} \quad \text{otherwise}
    \end{cases}$$
![[04 - Resources/Assets/E2 Page 2 of SU(3) MA6012.png| center | 450]]
Through this, we can see that the only non-trivial cohomology groups for $E_3$ we have to concern ourselves with are again 
$$\begin{aligned}
    &E_{3}^{0,0} = \frac{\ker[d: \R \to \set{0}]}{\im[d: \set{0} \to \R]} \cong \R \\
    &E_{3}^{0,3} = \frac{\ker[d: \R \to \set{0}]}{\im[d: \set{0} \to \R]} \cong \R \\
    &E_{3}^{5,0} = \frac{\ker[d: \R \to \set{0}]}{\im[d: \set{0} \to \R]} \cong \R \\
    &E_{3}^{5,3} = \frac{\ker[d: \R \to \set{0}]}{\im[d: \set{0} \to \R]} \cong \R
\end{aligned}$$

This logic can be continued, since the only way we could achieve a differential map not described above would be for $p = 5$, meaning it would need to have bi-degree $(5, -4)$. This means that the only differentials we can even consider to be non-trivial are $d_5^{p, q}: E_5^{p,q} \to E_5^{p+5,q-4}$. It is obvious that these differentials will still in any case be trivial, giving us the collapse of the spectral sequences, meaning 
$$E_2 = E_\infty$$
Due to the theorem on Serre spectral sequence we can now determine the cohomology groups via $E_{2}^{p,q} = H^{p+q}(SU(3))$ which results in
$$H^k(SU(3)) = \bigoplus_{p + q = k} E_2^{p, q}$$
Since knowing that $dim(SU(3)) = 8$ we can limit our calculations to $k \leq 8$
$$\begin{matrix}
    H^{0}(SU(3)) = \R && H^{3}(SU(3)) = \R && H^{6}(SU(3)) = 0\\
    H^{1}(SU(3)) = 0 && H^{4}(SU(3)) = 0 && H^{7}(SU(3)) = 0\\
    H^{2}(SU(3)) = 0 && H^{5}(SU(3)) = \R && H^{8}(SU(3)) = \R
\end{matrix}$$
meaning the Poincaré Polynomial of $SU(3)$ is given by
$$P_{SU(3)}(t) = 1 + t^{3} + t^{5} + t^{8} = (1 + t^{3})(1 + t^{5})$$


### Generalising to $SU(n)$
To generalise this procedure into an inductive proof, we need to establish a few points first. We will define a counting function which will count some sum of odd numbers but will ultimately give us a way to determine the Betti numbers of $SU(n)$ given some properties it has.

> [!definition|4.2.1]
> We will define a family of counting functions $M_n: \mathbb{N}_0 \to \mathbb{N}_0$ for $n \geq 2$ in the following way:
> $$M_n(k) = \left\lvert \set{\set{\alpha_2, \ldots, \alpha_n} \subset \mathbb{N}_0 \,\middle|\, \sum\limits_{i = 2}^n \alpha_i = k, \quad\forall i \in \set{2, 3, \ldots, n}: \alpha_i \in \set{0, 2i-1}} \right\rvert$$

This counting function seems to be convoluted in its definition, but we will see later that it has a natural connection to polynomial multiplication. We will require the following inductive property for it

> [!proposition|4.2.2]
> $$M_n(k) = M_{n-1}(k) + M_{n-1} (k - 2n + 1)$$

`\begin{proof}`
First observe that our function counts the sum of the form $\sum\limits_{i = 1}^n \alpha_i = k$ which can be dissected as
$$k = \sum\limits_{i = 1}^n \alpha_i = \sum\limits_{i = 1}^{n-1} \alpha_i + \alpha_n$$
Now consider that our only possibilities for $\alpha_n$ are $0$ or $2n - 1$ which we can count separately, thus having 
$$\begin{aligned}
        M_n(k) &= \left\lvert \set{\set{\alpha_2, \ldots, \alpha_n} \subset \mathbb{N}_0 \,\middle|\, \sum\limits_{i = 2}^n \alpha_i = k, \quad\forall i \in \set{2, 3, \ldots, n}: \alpha_i \in \set{0, 2i-1}} \right\rvert \\
        &= \left\lvert \set{\set{\alpha_2, \ldots, \alpha_n} \subset \mathbb{N}_0 \,\middle|\, \sum\limits_{i = 2}^{n-1} \alpha_i = k, \quad\forall i \in \set{2, 3, \ldots, n}: \alpha_i \in \set{0, 2i-1}} \right\rvert \\
        &+ \left\lvert \set{\set{\alpha_2, \ldots, \alpha_n} \subset \mathbb{N}_0 \,\middle|\, \sum\limits_{i = 2}^{n-1} \alpha_i + 2n - 1 = k, \quad\forall i \in \set{2, 3, \ldots, n}: \alpha_i \in \set{0, 2i-1}} \right\rvert
    
\end{aligned}$$
Now notice that using $\sum\limits_{i = 2}^{n-1} \alpha_i + 2n - 1 = k \iff \sum\limits_{i = 2}^{n-1} \alpha_i = k - 2n + 1$ these cardinalities are simply the functions $M_{n-1}$ and thus
$$M_n(k) = M_{n-1}(k) + M_{n-1} (k - 2n + 1)$$
`\end{proof}`

To understand better what this function counts we will calculate the first two examples.

> [!example|4.2.3]
> 1.  $n = 2$: It is useful to consider what $\alpha_i$ we are allowed to sum over. In this case, this is simply $\alpha_2 \in \{0, 3\}$, which makes our sum trivial, and we can see that $M_2(0) = M_2(3) = 1$ and
> $$\forall k \in \mathbb{N}_0 \setminus \{0, 3\}: \quad M_2(k) = 0$$
> 
> 2.  $n = 3$: Here we have the following $\alpha_i$:
>     $$\alpha_2 \in \{0, 3\}, \quad \alpha_3 \in \{0, 5\}$$
> 	We now haveto consider what sums are possible with these numbers to determine which $k$ result in a non-zero $M_3(k)$. We can simply count our options manually: 
> 	$$\begin{aligned}
> 		0 + 0 &= 0, \\
> 		0 + 3 &= 3, \\
> 		0 + 5 &= 5, \\
> 		5 + 3 &= 8,
> 	\end{aligned}$$
> 	which results in the values: 
> 	$$M_3(k) =
> 		\begin{cases}
> 			1  \quad k \in \{0, 3, 5, 8\} \\
> 			0  \quad \text{otherwise}
> 		\end{cases}$$

Note that this counting becomes very complicated to calculate rather quickly. Some intuition behind the complexity is given by the following proposition.

> [!proposition|4.2.4]
> Let $k\in \mathbb{N}$ and $M_k$ be as defined above. Then we have that
$$\dim(\Lambda^k[x_3, \ldots, x_{2n-1}]) = M_n(k)$$

`\begin{proof}`
Consider the Basis $B$ of $\Lambda[x_3, \ldots, x_{2n-1}]$ and let $I = \set{3, 5, \ldots, 2n-1}^k$. Then we can explicitly express the basis $B$ of $\Lambda^k[x_3, \ldots, x_{2n-1}]$ by
$$B = \set{\alpha = \prod\limits_{(i_1, \ldots, i_k) \in I} x_{i_k} \midline \deg(\alpha) = k}$$
noting that $\deg(\alpha) = \sum_{(i_1, \ldots, i_k) \in I} \deg(x_{i_k}) = \sum_{(i_1, \ldots, i_k) \in I} i_k$ we can rewrite
$$B = \set{\prod\limits_{(i_1, \ldots, i_k) \in I} x_{i_k} \midline \sum\limits_{(i_1, \ldots, i_k) \in I} i_k = k}$$
This gives us cardinality equivalence to the set
$$|B| = \left| \set{(i_1, \ldots, i_k) \in I \midline \sum\limits_{(i_1, \ldots, i_k) \in I} = k} \right|$$
`\end{proof}`

We will format the data differently later to simplify this, but for now, we can use this counting function to determine the de Rahm cohomology of $SU(n)$. First, we can prove a more general result following calculations seen in Section 5.2 of [@mccleary_2008] and Proposition 7.4 of [@prasad_spectral_sequences].

> [!theorem|4.2.5]
> Let $n \geq 2$, then
> $$H^\ast (SU(n)) \cong \Lambda[x_3, x_5, \ldots, x_{2n-1}]$$

`\begin{proof}`
We will prove this via Induction. Notice that for the case of $n = 2$ we know that $SU(2) \cong S^3$, meaning by [[3. Generalising Connectedness#^11b039]]
$$H^\ast (SU(2)) \cong H^\ast (S^3) \cong \Lambda[x_3]$$

Assuming that $H^\ast (SU(n-1)) \cong \Lambda[x_3, x_5, \ldots, x_{2n-3}]$ let us consider the cohomology of $SU(n)$. We have already seen that we have the following fibre bundle structure

![[04 - Resources/Assets/Bundle Structure SU(n) MA6012.png| center | 300]]

The Serre spectral Sequence now has the following $E_2$ Page.
$$E_2^{p, q} = H^p(S^{2n-1}) \otimes H^q(SU(n-1))$$
Since we already know that
$$H^p(S^{2n-1}) \cong \begin{cases} \R \quad q \in \set{0, 2n-1} \\ 0 \quad \text{otherwise}\end{cases}$$
our $E_2$ page has the following form

![[04 - Resources/Assets/SS Page for SU(n) MA6012.png| center |]]

If we now consider the differentials of this sequence
$$d_r^{p, q}: E_r^{p,q} \to E_r^{p+r, q+1-r}$$
we can see that for any $r < 2n-1$ we are in the situations of the example calculation above, this means our cohomology groups for the next page stay constant, giving us $E_2 = E_3 = \ldots = {E_2n-2}$. The only candidate for a differential that may change the convergence is $d_{2n-1}$ since this has bidegree $(2n-1, 2-2n)$ which means it can act on elements of $E_{2n-1}^{0, q}$ mapping to $E_{2n-1}^{2n-1, q+2-2n}$ for some $q \in \N$.

We can already describe how the differential acts on elements from $E_{2n-1}^{0, q}$ for $q \leq 2n - 3$. For these, the differentials maps
$$E_{2n-1}^{0, q} \to E_{2n-1}^{2n-1, q -2n + 2}$$ 
and since $q+ 2-2n \leq 2n-3 +2 -2n = -1$ we get that $E_{2n-1}^{2n-1, q -2n + 2} = 0$. For higher $q$, we need to use our induction hypothesis and notice that 
$$E_{2n-1}^{0, \ast} = \bigoplus_q E_{2n-1}^{0, q} = \bigoplus_q H^{q}(SU(n-1)) = H^\ast (SU(n-1)) \cong \Lambda[x_3, \ldots, x_{2n-3}]$$
using the generators of $\Lambda[x_3, \ldots, x_{2n-3}]$ we can now reduce the behaviour of $d_{2n-1}$ to the behaviour on the generators. Since $x_i \in E_{2n-1}^{0, i}$ and $i \leq 2n-3$ we already know that
$$d_{2n-1}(x_i) = 0$$
For any homogenous components of degree greater than $2n-3$ we must have a composite generator consisting of the products of some $x_i$ and we can apply the Leibniz property of the differential to get that for any $n \in \N$ some generator of $E_{2n-1}^{0, q} \ni \prod\limits_{k=1}^n x_{i_k}$ 
$$\begin{aligned}
        d_{2n-1} \left( \prod\limits_{k=1}^n x_{i_k} \right) &=  d_{2n-1}(x_{i_1}) \prod\limits_{k=2}^n x_{i_k} - d_{2n-1} \left( \prod\limits_{k=2}^n x_{i_k} \right) x_{i_1} \\
        &= - d_{2n-1} \left( \prod\limits_{k=2}^n x_{i_k} \right) x_{i_1} \\
        &= -d_{2n-1}(x_{i_2}) \prod\limits_{k=3}^n x_{i_k} x_{i_1} + d_{2n-1} \left( \prod\limits_{k=3}^n x_{i_k} \right) x_{i_2} x_{i_1}\\
        &\vdots \\
        &= d_{2n-1}(x_{i_n}) x_{i_{n-1}} \ldots x_{i_2} x_{i_1} \\
        &= 0    
\end{aligned}$$
In the end, this means that applying $d_{2n-1}$ to any element in $E_{2n-1}^{0, \ast}$ results in $0$ which means $d_{2n-1}$ is trivial. For any $r> 2n-1$ we can easily see again that $d_r$ is trivial since either the domain or codomain are trivial. Meaning our sequence collapses at the $E_2$ page 
$$E_2 = E_\infty$$
We can now consider a generator of $E_\infty^{2n-1,0} = H^0(SU(n-1)) \cong \R$ and denote it $x$. Finding a representation for generators of $E_\infty^{2n-1, q}$ for $q > 0$ now can be achieved by using the product on $E_\infty$ and a product of $E_\infty^{0,q} \times E_\infty^{2n-1,0} \to E_\infty^{2n-1,q}$. This gives us that for any $i \in \set{3, 5, \ldots, 2n-3}$ we have that $E_\infty^{2n-1, i}$ is generated by $x \cdot x_i$.

Note that now $H^k(SU(n) = \bigoplus\limits_{i+j = k} E_\infty^{i, j}$ by the convergence of our spectral sequence. Since $E_\infty^{p,q} = 0$ for $p \neq 0$ or, $2n-1$ we can simplify this expression to
$$H^k(SU(n)) = \bigoplus_{i+j=k} E_\infty^{i, j} = E_\infty^{0,k} \oplus E_\infty^{2n-1, k - (2n-1)}$$
This means that since $H^{2n-1}(SU(n)) = E_\infty^{0,2n-1} \oplus E_\infty^{2n-1, 0} = E_\infty^{2n-1, 0} \cong \Span_\R \set{x}$ we know that $\deg(x) = 2n-1$ in $H^\ast(SU(n))$ giving us
$$\begin{aligned}
        H^\ast(SU(n)) &= \bigoplus_{k = 0} H^k(SU(n)) \\
        &= \bigoplus_{k = 0} \left( E_\infty^{0,k} \oplus E_\infty^{2n-1, k - (2n-1)} \right)\\
        &= \bigoplus_{k = 0} E_\infty^{0,k} \oplus \bigoplus_{k = 0} E_\infty^{2n-1, k - (2n-1)}\\
        &\cong \Lambda[x_3, x_5, ..., x_{2n-3}] \oplus \Lambda[x_3, x_5, ..., x_{2n-3}, x]\\
        &\cong \Lambda[x_3, x_5, ..., x_{2n-3}, x]
    
\end{aligned}$$
with $\deg(x) = 2n-1$
`\end{proof}`

This theorem gives us a slightly convoluted way to describe the cohomology groups of $SU(n)$ completely. We can simplify this by using the previous proposition and our counting function.

> [!corollary|4.2.6] Dimension of $k$-th Cohomology Group of $SU(n)$
> $$H^k(SU(n)) \cong \R^{M_n(k)}$$

`\begin{proof}`
Simply note that $\dim(H^k(SU(n))) = \dim(\Lambda^k[x_3, \ldots, x_{2n-1}]) = M_n(k)$
`\end{proof}`

We can shed even more light onto this result and the definition of $M_n$ by considering the Poincaré Polynomial of $SU(n)$. We can observe that we can simplify the Polynomial in the following way 
$$\begin{aligned}
    P_{SU(n)}(t) &= \sum\limits_{k \in \mathbb{N}_0} \beta_k(SU(n)) t^k \\
    &= \sum\limits_{k \in \mathbb{N}_0} \dim H^k(SU(n)) t^k \\
    &= \sum\limits_{k \in \mathbb{N}_0} M_n(k)t^k \\
    &= \sum\limits_{k \in \mathbb{N}_0} M_{n-1}(k) + M_{n-1}(k - (2n-1))t^k \\
    &= \sum\limits_{k \in \mathbb{N}_0} M_{n-1}(k) t^k + \sum\limits_{k \in \mathbb{N}_0} M_{n-1}(k - (2n-1)) t^k \\
    &= \sum\limits_{k \in \mathbb{N}_0} M_{n-1}(k) t^k + \sum\limits_{j \in \mathbb{N}_0} M_{n-1}(j) t^{j} t^{2n -1} \\
    &= \sum\limits_{k \in \mathbb{N}_0} M_{n-1}(k) t^k \cdot \left( 1 + t^{2n-1} \right) \\
    &= P_{SU(n-1)}(t) (1 + t^{2n-1})
\end{aligned}$$
Arguing this inductively gives us the following Statement.


> [!corollary|4.2.7] Poincaré Polynomial of $SU(n)$
> The Poincaré Polynomial of $SU(n)$ is given by
> $$P_{SU(n)}(t) = (1 + t^3)(1 + t^5)\ldots(1 + t^{2n-1}) = \prod_{k = 2}^n (1 + t^{2k-1})$$

`\begin{proof}`
We prove this inductively. The base case is given by $n = 2$, here we have $SU(2) \cong S^3$ which means that
$$P_{SU(2)}(t) = P_{S^3}(t) = 1 + t^3$$
Now let us assume it holds for $n-1$, then by the above given logic we get
$$P_{SU(n)}(t) = P_{SU(n-1)}(t) (1 + t^{2n-1})$$
Which by our induction hypothesis gives us
$$P_{SU(n)}(t) = \prod_{k = 2}^{n-1} (1 + t^{2k-1})(1 + t^{2n-1}) = \prod_{k = 2}^n (1 + t^{2k-1})$$
`\end{proof}`

Extending this to the Poincaré polynomials of $U(n)$ is a simple application of the Künneth Formula or multiplicativity.

> [!corollary|4.2.8] Poincaré Polynomial of $U(n)$
> The Poincaré Polynomial of $U(n)$ is given by
> $$P_{U(n)}(t) = \prod_{k = 1}^n (1 + t^{2k-1})$$

`\begin{proof}`
Applying the homeomorphism $U(n) \cong SU(n) \times U(1) \cong SU(n) \times S^1$ and the multiplicativity of the Poincaré polynomial, we get
$$P_{U(n)}(t) = P_{SU(n)}(t) \cdot P_{S^1}(t) = P_{SU(n)}(t)\cdot(1+t) = \prod_{k = 1}^n (1 + t^{2k-1})$$
`\end{proof}`

This already allows us to nicely write down the Betti numbers of $U(n)$ and $SU(n)$, and also shows the motivation behind the definition of $M_n$, since we can view it as the set of degrees resulting from simplifying the Poincaré polynomial. This is compactly formulated in the following corollary. 

> [!corollary|4.2.9] Homology Equivalence Between Unitary Groups and the Product of Odd Dimensional Spheres
> The compact Lie Groups $U(n)$ and $SU(n)$ are cohomology equivalent to the spaces $\prod\limits_{k = 1}^n S^{2k-1}$ and $\prod\limits_{k = 2}^n S^{2k-1}$ respectively, meaning 
> $$\begin{aligned}
>         H^{\ast} (SU(n)) &= H^{\ast}\left(\prod_{k = 2}^n S^{2k-1}\right) \\
>         H^{\ast} (U(n)) &= H^{\ast}\left(\prod_{k = 1}^n S^{2k-1}\right)   
> \end{aligned}$$

^888ac9

`\begin{proof}`
This is a simple consequence of the multiplicative nature of the Poincaré polynomial. For $X = \prod\limits_{k = 1}^n S_{2k-1}$
$$P_X (t) = \prod_{k = 1}^n P_{S^{2k-1}}(t) = \prod_{k = 1}^n (1 + t^{2k-1}) = P_{U(n)} (t)$$
Analogously for $SU(n)$.
`\end{proof}`

## Further Invariants: The Euler Characteristic

We have already touched on how the Poincaré polynomial is not only a source of structure for our data, but also transfers some nice computational properties to Betti numbers. An aspect we haven't mentioned, though, is that the evaluation of the Poincaré polynomial at any value of $t$ must be an intrinsic value associated to our Manifold. In the sense that it is just as topologically invariant as the Betti numbers themselves. The most useful evaluation of our Poincaré polynomial is given by $t = -1$, which turns out to be the Euler-Characteristic $\chi(M)$ for general smooth manifolds.

On $U(n)$ and $SU(n)$ this Euler-Characteristic is a topological property that is now easily computable as 
$$\begin{aligned}
    \chi(U(n)) &= P_{U(n)}(-1) = \prod_{k = 1}^n (1 + (-1)^{2k-1}) = 0 \\
    \chi(SU(n)) &= P_{SU(n)}(-1) = \prod_{k = 2}^n (1 + (-1)^{2k-1}) = 0
\end{aligned}$$
With this result, we can claim even more topological properties, which are based on the Euler Characteristic. Apply, for example, the Poincaré-Hopf theorem, and we can state that there exists a nowhere vanishing vector field on $U(n)$ and $SU(n)$. Lacking time, we won't go into these properties further, but one can refer to [@hopf_vektorfelder_1927] for the original statement of the Poincaré-Hopf theorem.
