# Parallel Transport

**Previous**: [[4.1 (semi-) Riemannian Metrics MA3205]]
**Next**: [[5.1 The Curvature Tensor MA3205]]

Given a curve $\gamma$ and a vector field $V$ along $\gamma$ we would like to write something like $\nabla_{\gamma'}V$. The problem being that $V$ is not defined on our manifold but rather along $\gamma$. $\gamma'$ requires a bit of finessing but works out ok since the lower slot is $\mathcal{F}(M)$-Linear so we can just replace it with any vector field on $M$ such that $V(p) = \gamma'_{p}$.
The plan to solve the problem of $V$ is to extend it in some sense and then take the derivative and make sure that this is independent of the choice of extension.

Let us extend $X$ to $\tilde X \in \Gamma(TM)$. Then in coordinate system we get $\nabla_{\gamma'} \tilde X = \sum\limits_{i} (\gamma')^{i} \sum\limits_{k} \left( \del_{i} \tilde X^{k} + \sum\limits_{j} \Gamma_{ij}^{k} \tilde X^{j} \del_{k} \right) = D_{\gamma'} \tilde X + \sum\limits \tilde X^{j} \nabla_{\gamma'}(\del_{j})$
note that $D_{\gamma'} \tilde X = D_{\gamma}\tilde X (\gamma') = \gamma'(\tilde X \circ \gamma) = \at{\sum\limits_{i} \gamma'^{i} \del_{i} \left( \sum\limits_{k} \tilde X^{k} \del_{k} \right)}{\gamma}$ where the right hand side only evaluates $\tilde X$ along $\gamma$. So we can write
$\nabla_{\gamma'} \tilde X = D_{\gamma}X(\gamma') + \sum\limits X^{j} \nabla_{\gamma'}(\del_{j})$
and therefore $\nabla_{\gamma'}X$ is well-defined

> [!definition]
> Let $\gamma: I \to M$ be a regular curve. A vector field $X$ along $\gamma$ ([^1]) is called parallel if and only if $\nabla_{\gamma'}X = 0$. $\gamma$ is called a geodesic if $\gamma'$ is parallel (and thus $\nabla_{\gamma'}\gamma' = 0$).

> [!lemma]
> Let $g: I \to M$ be a regular curve, $t_{0} \in I$ and $X_{0} \in T_{\gamma(t_{0})}M$. Then there is a unique parallel vector field $X$ along $\gamma$ with $X(t_{0}) = X_{0}$

`\begin{proof}`
Writing the condition to be parallel in a coorinate system gives us a linear system of ODEs:
With $\phi = (x_{1}, \ldots, x_{n})$

$$$\begin{align*}
\nabla_{\gamma'} X &= \sum\limits_{i} \frac{d \gamma^{i}}{dt} \nabla_{\del_{i}}X \\
&=  \sum\limits_{k} \left( \frac{d X^{k}}{dt} + \sum\limits_{ij} \Gamma_{ij}^{k} \frac{d x^{i} \circ \gamma}{dt} \right)
\end{align*}$$
So $\nabla_{\gamma'} X = 0$ is indeed a linear system of ordinary differential equations.
`\end{proof}`


> [!lemma]
> If $X$ and $Y$ are parallel along $\gamma$ then $\innprod{X}{Y}$ is constant (along the curve).

`\begin{proof}`
$$\gamma' (\innprod{X}{Y}) = \innprod{\nabla_{\gamma'}X}{Y} + \innprod{X}{\nabla_{\gamma'}Y} = 0{}$$
`\end{proof}`

> $$\nabla_{X}Y = \frac{1}{2} [X, Y] \iff \nabla_{X} X = 0$$
> since on one hand $[X, X] = 0$ and also $0 =\nabla_{Y-Z}(Y-Z) = \nabla_{Y} Y - \nabla_{Y} Z + \nabla_{Z} Z - \nabla_{Z} Y = 0 - \nabla_{Y} Z + 0 - \nabla_{Z} Y \implies \nabla_{Y} Z = -\nabla_{Z} Y$ but also $[Y, Z] = \nabla_{Y} Z - \nabla_{Z} Y = \frac{1}{2} [Y, Z]$

> [!corollary]
> Parallel transport furnishes an isometry and thus preserves causal type.

## Exponential Map
In the same vein as the last example we can, given a point $p \in M$ map a neighbourhood $U \subset T_{p} M$ of $0$ onto $M$ via geodesic lines. The geodesic equation in this situation is given by
$$0 = \nabla_{\gamma'} \gamma' = \sum\limits_{k} \left( \frac{d^{2} x^{k} \circ \gamma}{dt^{2}} + \sum\limits_{i,j} \Gamma_{ij}^{k} \frac{dx^{i} \circ \gamma}{dt} \frac{dx^{j} \circ \gamma}{dt} \right) \del_{k}$$

Since this again is a 2nd order system of ordinary differential equations we can solve it locally giving us

> [!lemma]
>For any $v \in T_{p} M$, $v \neq 0$ there is an interval $I \subset \R$ around $0$ and a unique geodesic $\gamma: I \to M$ such that $\gamma(0) = p$ and $\gamma'(0) = v$

using this we extend the exponential map to general manifold using these geodesics. Keep in mind that because of the previous example these geodesic constructions of exponentials correspont to the usual exponential on lie groups.

> [!definition] Exponential Map using Geodesics
> For $p \in M$ let $D_{p} \subset T_{p} M$ be the set of all vectors $v$ such that the maximal geodesic $\gamma_{v}$ is defined at least on $[0,1]$. Then the exponential map $$\exp: D_{p} \to M$$ is defined as $$\exp(v) = \gamma_{v}(1)$$
> 

A neighbourhood $U$ of $p$ that is the diffeomorphic image of a starshaped neighbourhood $D_{p}$ of $0 \in T_{p} M$ under the exponential map is called a normal neighbourhood of $p$.
