# Jacobi Fields

**Previous**: [[7. General Relativity MA3205]]
**Next Chapter**: [[9. Local Symmetry MA3205]]

Given a curve $\gamma: [a, b] \to M$, a variation of $\gamma$ is a map $\delta: [a, b] \times (-\epsilon, \epsilon) \to M$ with $\delta(t, 0) = \gamma(t)$ for all $t \in [a, b]$. We can also define $V(t) = \del_{u} \delta(t, u) \mid_{u=0} =: \delta_{u}(t, 0)$ which we will call the variation vector field. If all $\delta(\cdot, u)$ are geodesics, $\delta$ is called a geodesic variation.

> [!definition] Jacobi Vector Fields
> If $\gamma$ is a geodesic, a vector field $Y$ along $\gamma$ satisfying
> $Y'' = \nabla_{\gamma'} Y = R_{Y \gamma'}\gamma'$
> is called a Jacobi Field.

> [!lemma]
> The Variation vector field of a geodesic variation is a Jacobi field.

`\begin{proof}`
We need to calculate $\delta_{utt} = Y''$ but first note that $\delta_{tt} = 0$ since $\delta_{tt} = \nabla_{\gamma'} \delta_{t} = \nabla_{\gamma'} \gamma' = 0$ since $\gamma$ is a geodesic.
Next we show that $\delta_{ut} = \delta_{tu}$. For this write $X = \delta_{t}$ and $Y = \delta_{u}$, then

$$$\delta_{ut} = \nabla_{X} Y = \sum\limits_{k} \left( \frac{\del}{\del t} Y^{k} + \sum\limits_{ij} \Gamma^{k}_{ij} Y^{i} \frac{\del \delta^{j}}{\del t}\right) 
= \sum\limits_{k} \left( \frac{\del}{\del t} \frac{\del}{\del u} \delta^{k} + \sum\limits_{ij} \Gamma^{k}_{ij} \frac{\del \delta^{i}}{\del u} \frac{\del \delta^{j}}{\del t}\right)$$
by swapping $i, j$ and using schwarz lemma we get that thus
$$\delta_{ut} = \delta_{tu}$$
Now we can calculate that $X_{tu} - X_{ut} = R_{XY} X$ since
$$R_{XY} X = \nabla_{[X,Y]}X - \nabla_{X} \nabla_{Y} X + \nabla_{Y} \nabla_{X} X$$
since $[X, Y] = 0$ and also since $\nabla_{Y} X = X_{u}$ and $\nabla_{X} X = X_{t}$ we get
$$R_{XY} X = - X_{ut} + X_{tu}$$
Due to their definitions we get
$$Y'' = \delta_{utt} = \delta_{tut} = X_{ut} = \delta_{ttu} - R_{\delta_{t} \delta_{u}} \delta_{t} = 0 - R_{\delta_{t} \delta_{u}} \delta_{t} = R_{\delta_{u} \delta_{t}} \delta_{t}$$
since $\gamma' = \delta_{t}$ we have what we wanted that
$$Y'' = R_{\delta_{u} \gamma'} \gamma'$$
`\end{proof}`


> [!example]
> On $S^2$ we look at $\delta(t, u) = \begin{pmatrix}\cos u \cos t  \\ \sin u \cos t \\ \sin t\end{pmatrix}$ then this is a geodesic variation of $\gamma(t) = \begin{pmatrix}\cos t \\ 0 \\ \sin t\end{pmatrix}$. But note that $\delta$ is only a tangential vector field along $\gamma$ not in general.
> Calculating the variation vector field we get
> $$V(t) = \delta_{u}(t, 0) =\at{\begin{pmatrix}\cos t \cdot -\sin(u) \\ \cos t \cdot \cos u \\ 0\end{pmatrix}}{u =0} = \begin{pmatrix}0 \\ \cos t \\ 0\end{pmatrix}$$
> and calculating $V''$ we simply get
> $$V''(t) = - \cos t \del_{y} = - V$$
> where we used that $\delta_{y}$ actually is parallel along $\gamma$ so $\nabla_{\gamma'}(f \del_{y}) = f' \del_{y} + 0$
> 
> Next we can compute that the following holds $\innprod{R_{V \gamma'}\gamma'}{V} = - \innprod{R_{V \gamma'} V}{\gamma'}$
> note that for this we can use the secitonal curvature of the sphere
> $$-1 = K(V, \gamma') = \frac{\innprod{R_{V \gamma'} V}{\gamma'}}{g_{11} g_{22} - g_{12}^{2}} 
> \implies \innprod{R_{V \gamma'} V}{\gamma'} = - g_{11} g_{22} = -\cos^{2}t = - \innprod{V}{V}$$
> which gives us that $R_{V \gamma'} \gamma' = - V = V''$ so the Jacobi equation holds as we have proven it should.


> [!lemma]
> Let $\gamma$ be a geodesic through $p = \gamma(0)$ and $v, w \in T_{p}M$. Then there is a unique Jacobi field $Y$ on $\gamma$ such that $Y(0) = v$ and $Y'(0) = w$

`\begin{proof}`
Assume $E_{1}, \ldots, E_{n}$ are ON Basis of $T_{p}M$. It can be extended parallely along $\gamma$. Write
$$Y = \sum\limits_{i} Y^{i} E_{i} \quad v = \sum\limits_{i} v^{i} \at{E_{i}}{i = 0} \quad w = \sum\limits_{i} w^{i} \at{E_{i}}{i = 0} \quad \gamma' = \sum\limits_{i} a^{i} E_{i}$$
with constant $a^{i}$ since the ON-Basis is parallel transported along $\gamma$. Then we get the following for our initial conditions
$$Y(0) = v \iff Y^{i}(0) = v^{i} \iff \frac{dY^{i}}{ds} (0) = w^{i}$$
which means that the Jacobi equation becomes a linear system:
$$\frac{d^{2}Y^{m}}{ds^{2}} = \sum\limits_{ijk} R^{m}_{ijk} a^{i} Y^{j} a^{k}$$
for all $m$. This is a linear system of differential equations, meaning we can always solve it and obtain a solution space of dimension $2n$
`\end{proof}`


> [!proposition]
> For $p \in M$ and $x \in T_{p} M$ and $v \in T_{x}(T_{p} M) \cong T_{p} M$ we get that
> $$d \exp_{p}(v_{x}) = V(1)$$
> where $V$ is the unique jacobi field on $\gamma_{x} = \exp(\cdot x)$ with $V(0) = 0$ and $V'(0) = v$ 

`\begin{proof}`
Look at the map $(t, s) \mapsto t(x+sv) \in T_{p} M$ with $t \in [0,1]$ and $|s|$ small. Set $x(t, s) = \exp_{p}(t(x+sv)) = \gamma_{x+sv}(t)$. Then we can see that $x(t, s)$ is in fact a geodesic variaction and $\del_{s} \gamma(u, 0) = d \exp_{p}(ux)(uv) = V(u)$ is the jacobi field on $\gamma_{x}$. At $t = 1$ we find that
$$(1, s) \mapsto (x+ sv)$$ so $V(1) = d \exp_{p} (v)$. At $t = 0$ we have $(0, s) \mapsto 0$ so $V(0) = 0$. Then this means $V'(0) = x_{st}(0,0) = x_{st}(0, 0)$ as seen before. But $s \mapsto x_{t}(0, s) = x + sv$ so $x_{ts}(0, s) = v$
`\end{proof}`


## Tidal Forces
We will call a vector field $V$ along $\gamma$ perpendicular if $\innprod{\gamma'}{V} = 0$ and tangent if $Y = f \gamma'$ for some function $f$. If $| \gamma' | > 0$ we can decompose any vector field $Y$ into a tangential and perpendicular part.
$$Y = Y^{\top} + Y^\perp$$
Now if $\gamma$ is a geodesic then $Y \perp \gamma \implies Y' \perp \gamma$ since using $\frac{d}{dt} \innprod{Y}{\gamma'} = \innprod{Y'}{\gamma'} + \innprod{Y}{\gamma''} = \innprod{Y'}{\gamma'}$ and likewise for tangency. This means that for non-null geodesics we get
$$(Y')^{\top}= \left( Y^{\top} \right)' \quad (Y')^{\perp}= \left( Y^{\perp} \right)'$$

> [!lemma]
> Let $Y$ be a vector field along a geodesic $\gamma$. Then
> 1. If $Y$ is tangent then $Y$ is a jacobi field if and only if $Y'' = 0$ meaning $Y(s) = (as + b) \gamma'$
> 2. If $Y$ is a Jacobi field then $Y \perp \gamma$ if and only if there exists $a, b$ with $a \neq b$ such that $Y(a) \perp \gamma$ and $Y(b) \perp \gamma$  (this is equiavelnt to simply having $a$ such that $Y(a) \perp \gamma$ and $Y'(a) \perp \gamma$)
> 3. If $\gamma$ is a non-null curve then $Y$ is a jacobi field if and only if $Y^\perp$ and $Y^{\top}$ are Jacobi fields. 

`\begin{proof}`
1. Assuming $Y$ is  tangential to $\gamma$ we get that $Y = f \gamma'$. This means that $Y' = f' \gamma'$ and $Y'' = f'' \gamma'$. The Jacobi equation reads 
$$Y'' = R_{Y \gamma'} \gamma' = 0$$
since $\gamma'$ and $Y$ are parallel. This means that $f'' = 0$ giving us that $f(s) = as + b$.
2. Assume $Y$ is a Jacobi field. Since we then know that $\frac{d^{2}}{ds^{2}} \innprod{Y}{\gamma'} = \frac{d}{ds} \innprod{Y'}{\gamma'} + 0 = \innprod{Y''}{\gamma'}$. So $$Y \perp \gamma \implies \innprod{Y''}{\gamma'} = 0 \iff \innprod{Y}{\gamma'} = As + B$$
Then we get that $$Y \perp \gamma \iff 0 = \innprod{Y}{\gamma'} = As +B \iff A, B = 0 \iff \gamma \text{ has at least two points that are perpendicular to } Y$$
1. $R_{Y^{\top} \gamma'} = 0$, so $R_{Y \gamma'} \gamma' = R_{Y^{\perp} \gamma'} \gamma'$. Now skew-symmetry of $R$ gives us that $R_{Y \gamma'} \gamma' \perp \gamma'$ thus $Y'' = R_{Y \gamma'} \gamma'$ splits into $(Y^{T})'' = 0$ and $(Y^{\perp})'' = R_{Y^{\perp} \gamma' } \gamma'$
`\end{proof}`

> [!definition] The Tidal Force Operatro
> Let $p \in M, v \in T_{p} M, v \neq 0$, then $$F_{v}: v^{\perp} \to v^{\perp}, \quad F_{v}(w) = R_{wv}v$$
> is called the tidal force operator.

> [!lemma]
> The tidal force operator $F_{v}$ is self-adjoint linear operator on $v^{\perp}$ and $tr F_{v} = - Ricc(v, v)$

`\begin{proof}`
Linearity is given directly by the tensorial definition of $F_{v}$. It is also clear that it maps $v^{\perp}$ to $v^{\perp}$ since we can easily calculate
$$\innprod{R_{wv}v}{v} = 0$$
The self-adjointness is given by the following symmetry
$$\innprod{F_{v}(y)}{x} = \innprod{R_{yv}v}{x} = \innprod{R_{vx}y}{v} = \ldots = \innprod{y}{F_{v}(x)}$$

Note that if $v$ is null ( $\innprod{v}{v} {}= 0, v \neq 0$) then $v^{\perp}$ is degenerate in the sense that the metric breaks. If $v$ is non-null, choose $e_{2}, \ldots, e_{n}$ to be a ON basis in $v^{\perp}$. Then $Ricc(v, v)$ is given by
$$Ricc(v, v) = \sum\limits_{i} \epsilon_{i} \innprod{R_{v e_{i}}v}{e_{i}} = \sum\limits_{i} \epsilon_{i} (-\innprod{F_{v}(e_{i})}{e_{i}}) = - tr(F_{v})$$
If $v$ is a null vector, choose a $w$ in the light-cone such that $\innprod{v}{w} {} = -1$. Then $v$ and $w$ span a Lorentz plane $\Pi$. Set $e_{1} = \frac{v+w}{2}, \quad e_{2} = \frac{v-w}{2}$ which are now a basis of $\Pi$ aswell and $e_{1}$ is time-like and $e_{2}$ is space-like. Now choose $e_{3}, \ldots, e_{n}$ as ON Basis in $\Pi^{\perp} \subset v^{\perp}$. Then we get 
$$Ricc(v, v) = - \innprod{R_ve_{1}}{e_{1}} + \innprod{R_ve_{2}}{e_{2}} + \sum\limits_{j>2} \epsilon_{j} \innprod{R_{ve_{j}} v}{e_{j}}$$
Since we can simplify the first terms to
$$\innprod{R_{v e_{1}}v}{e_{1}} = \frac{1}{4} \innprod{R_{vw} w}{w} = \innprod{R_{v e_{2}} v}{e_{2}}$$
meaning the first two terms cancel. On the other hand $v, e_{3}, \ldots, e_{n}$ form a basis of $v^\perp$ but $F_{v}(v) = 0$ meaning
$$tr(F_{v}) = \sum\limits_{j>2} \epsilon_{j} \innprod{F_{v}(e_{j})}{e_{j}}$$
`\end{proof}`


Now given a freely falling observer $\gamma$ relative positions of (infinitesimal) neighbours are given by Jacobi fields $Y$ along $\gamma$. Changes in relative positions therefore are given by $Y''$ as relative accelerations. This is governed by the Jacobi equation
$$Y'' = R_{Y \gamma'} \gamma'$$
So for an instantaneous observer $u$ it can be measured by means of the tidal force $F_{n}$ on its rest space.

> [!example] Tidal Forces in Schwarzfield Model
> Let us look at a freely falling observer $\omega$ in the Schwarzschild model. Assume it moves on a radial geodesic. This means no angular momentum at infinity, meaning $L = 0$. > The geodesic equation can be solved by 
> $$t = \frac{1}{2} R \sqrt{\frac{R}{2M}(\eta + \sin \eta)} \quad r = \frac{1}{2}R (1 + \cos \eta)$$
> Using $R = 8M$ we get
> $$t = 8M(\eta + \sin \eta) \quad r = 4M(1 + \cos \eta) \implies \phi \circ \gamma(\eta) = 4M \begin{pmatrix}2\eta + 2 \sin \eta \\  1 + \cos \eta \\  0 \\  0\end{pmatrix}$$
> We write $\omega' = a \del_{t} + b \del_{r}$ with $a^{2} g_{00} + b^{2} g_{11} = -1$. We find that in $(\omega')^{\perp}$ the radial direction is $x = b g_{11} \del_{t} - a g_{00}\del_{r}$ and any $w \perp x$ is just tangent to $S^{2}(r)$.
> Calculating the tidal force we get
> $$F_{\omega'}(w) = R_{w \omega'} \omega' = a^{2} R_{w \del_{t}}\del_{t} + b^{2} R_{w \del_{r}} \del_{r}  = \frac{M}{r^{3}} \left( a^{2} g_{00} + b^{2} g_{11} \right) w = - \frac{M}{r^{3}} w$$
> Likeweise 
> $$F_{\omega'} (x) = 2 \frac{M}{r^{3}} x$$
