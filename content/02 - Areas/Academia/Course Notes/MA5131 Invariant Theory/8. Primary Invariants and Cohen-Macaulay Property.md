Let $G$ be a finite group and $V$ a $G$ module. We will alwas write $n = \dim(V)$. Assume that $\K = \bar{\K}$ for convenience sake.

The following definition is also a Lemma and requires input from Commutative Algebra.

> [!definition|8.1] Codimension
> For $S \subset \K[V]$ we write $\mathcal{V}(S) \subset V$ the affine variety in $V$. We write
> $\mathrm{cd}(S) = n - \dim(\mathcal{V}(S))$
> where the definition of dimension is imported from AG but is intuitive enough. This value is called the co-dimension of the variety induced by $S$.
> Homogeneous polynomials $f_{1}, \ldots, f_{k} \in \K[V]_{+}$ are called a partial homogeneous system of parameters _(phsop)_ if
> $\mathrm{cd(\set{f_{1}, \ldots, f_{k}})} = k$
> From commutative algebra we can import that $k$ is the maximal possible $\mathrm{cd}$. A phsop is called a hsop if $k = n$.

> [!lemma|8.2] PHSOP
> Let $I \subset \K[V]^{G}$ a homogeneous ideal (strict) and write $k = \mathrm{cd}(I)$. Then there is a phsop $f_{1}, \ldots, f_{k} \in I$.

`\begin{proof}`
Assume that $f_{1}, \ldots, f_{l} \in I$ are already an hsop with $l < k$. Then by defining $X = \mathcal{V}(I)$ and $Y = \mathcal{V}(f_{1}, \ldots, f_{l})$  and let $Z_{i}$ be the irreducible components of $Y$ which exist from commuitative algebra, then
$n - k = \dim(X) < \dim(Y) \leq \dim(Z_{i})$
for $i = 1, \ldots, r$. This tells us that for all $i$ we have
$Z_{i} \nsubseteq \mathcal{V}(I) \implies J = (I)_{\K[V]} \nsubseteq \mathcal{I}(Z_{i}) =: P_{i}$
where $P_{i}$ are prime ideals since $Z_{i}$ is irreducible. Another fact from CA is the concept of graded prime avoidance which tells us that there exists a $g \in J$ homogeneous with $g \neq P_{i}$ for all $i$, meaning there exists one element that avoids all. It is clear that $G$ permutes the $P_{i}$ since $Y$ is $G$-Stable. This gives us ultimately
$f := \prod_{\sigma \in G} \sigma(g) \not\in P_{i}$
We can now see that
$\mathcal{V}(f_{1}, \ldots, f_{l}, f) = Y \cap \mathcal{V}(f) = \bigcup_{i = 1}^{r} \left(Z_{i} \cap \mathcal{V}(f)\right)$
where each component is never left the same meaning $Z_{i} \cap \mathcal{V}(f) \not\subset Z_{i}$. Using the notation $Y' = \mathcal{f_{1}, \ldots, f_{l}, f}$ we can note that
$\dim(Y') < \dim Y$
It remains to show that $f \in I$. For this consider $g = \sum\limits_{i = 1}^{s} h_{i} f_{i}$ with $h_{i} \in \K[V], f_{i} \in I$. Consider a map
$\phi: \K[V][t_{1}, \ldots, t_{S}] \to \K[V], \quad t_{i} \mapsto f_{i}$
where the added variables have a trivial $G$ action. This map is $G$-equivariant. Since we can represent $g$ in a nice way by
$g = \phi\left(\sum\limits_{i = 1}^{s} h_{i} t_{i}\right)$ meaning that our $f$ from before can also be rewritten
$f = \prod_{\sigma \in G} \sigma \left(\phi\left(\sum\limits_{i = 1}^{s} h_{i} t_{i}\right)\right) = \prod_{\sigma \in G} \phi \left(\sigma\left(\sum\limits_{i = 1}^{s} h_{i} t_{i}\right)\right) = \phi \left(\prod_{\sigma} \sigma\left(\sum\limits_{i = 1}^{s} h_{i} t_{i}\right)\right) = \phi(F)$
where we simply define $F$ to be what is in the brackets. From the construction of $F$ we can see that $F \in \K[V][t_{1}, \ldots, t_{s}]^{G}$ which is equivalent to saying that all the coefficients are invariants, meaning $F \in \K[V]^{G}[t_{1}, \ldots, t_{s}]$. We know that this means that the constant coefficient is vanishing meaning
$F(t_{i} = 0) = 0$
giving us $f = \phi(F) \in I$ and thus
$\set{f_{1}, \ldots, f_{l}, f}$
is a phsop.

`\end{proof}`

A special case of this lemma is given when considering $I = \K[V]^{G}_{+}$. We can then ask what $\mathrm{cd}(I)$ is. For this we need to know $\mathcal{V}(I)$. We know that $0 \in \mathcal{V}(I)$.
Let $0 \neq v \in V$ then orbit seperation tells us that $\exists f \in \K[V]^{G}$ with $0 \not\in G(v)$. $f(v) \neq f(0)$ thus define $f* = f - f(0)$. Then $f* \in I$ with $f*(v) \neq 0$, so $\mathcal{V}(I) = \set{ 0}$. This gives us that $\mathrm{cd}(I) = n \implies \exists \text{hsop}$.

> [!theorem|8.3] Condition for Homogeneous System of Parameters
>
> 1. For homogeneous $f_{1}, \ldots, f_{n} \in \K[V]_{+}^{G}$ we have the equivalence $f_{1}, \ldots, f_{n} \text{ hsop} \iff \mathcal{V}(f_{1}, \ldots, f_{n}) = \set{0}$
> 2. An hsop exists.

Now let $f_{1}, \ldots, f_{n}$ be an hsop, then $\mathcal{V}(f_{1}, \ldots, f_{n}) = \set{0} = \mathcal{V}(x_{1}, \ldots, x_{n})$ where the $x_{i}$ are the variables in $\K[V]$. By Hilbert’s Nullstellensatz we get that
$\sqrt{(f_{1}, \ldots, f_{n})} = (x_{1}, \ldots, x_{n}) \iff \exists k: x_{i}^{k} \in (f_{1}, \ldots, f_{n})$
this tells us that $\faktor{\K[V]}{(f_{1}, \ldots, f_{n})}$ is a finite dimensional $\K$-Vector space generated by $\set{\prod x_{i}^{e_{i}} \midline 0 \leq e_{i} < k}$.  Now set $A := \K[f_{1}, \ldots, f_{n}] \subseteq \K[V]^{G} \subseteq \K[V]$ the subalgebra generated by the hsop and $M := \K[V]$ then we get
$A_{+} M = (f_{1}, \ldots, f_{n})_{\K[V]}$
Since $A_{+}$ contains all polynomials in $f_{i}$ and multiplying by all $g \in M$ amounts to generating the ideal. This means the previous statement about finite dimensionality is the same as stating as $\faktor{M}{A_{+} M }$ is finitely generated.

By applying graded nakayama we can conclude that $M$ is a finitely generated $A$-Module. Since $A$ is noetherian by definition we also know that any submodule is noetherian, meaning
$\K[V]^{G} \text{ is finitely generated as an } A \text{-Module}$

> [!theorem|8.4] Primary and Secondary Invariants
> Let $f_{1}, \ldots, f_{n} \in \K[V]^{G}$ is an hsop. Then there exists $g_{1}, \ldots g_{m} \in \K[V]^{G}$ homogeneous such that
> $\K[V]^{G} = \sum\limits_{i = 1}^{m} A \cdot g_{i}$
> with $A = \K[f_{1}, \ldots, f_{n}]$. Also $f_{1}, \ldots, f_{n}$ are algebraically independent, since the Krull-Dimension $\dim(A) = \dim(\K[V]) = n$.
> The $f_{i}$ in this context are called **primary invariants** and the $g_{i}$ are called **secondary invariants**. Also note that the primary and secondary invariants together generate the invariant ring as an algebra meaning
> $\K[V]^{G} = \K[f_{1}, \ldots, f_{n}, g_{1}, \ldots, g_{m}]$

From this we get a new formulation of Symonds degree bound

> [!theorem|8.5]
> Let $f_{1}, \ldots, f_{n} \in \K[V]^{G}$ hsop. Then there are secondary invariants $g_{1}, \ldots, g_{m}$ such that
> $\deg(g_{i}) \leq \sum\limits_{i = 1}^{n} (\deg(f_{i}) - 1)$

Theorem 7.4 follows from this statement with exercise 37.

## Cohen-Macaulay Property

> [!definition|8.6]
> $\K[V]^{G}$ is called Cohen-Macaulay (CM) if there exists an hsop $f_{1}, \ldots, f_{n}$ such that $\K[V]^{G}$ is free as an $A$-Module, $A = \K[f_{1}, \ldots, f_{n}]$

> [!example|\*]
> Consider $G = \set{id}$ and $f_{i} = x_{i}$, then $A = \K[V]$ and we can write $\K[V] = A \cdot 1$ free meaning $\K[V]$ is Cohen Macaulay

> [!theorem|8.7] Characterising Cohen-Macaulay
> If $\K[V]^{G}$ is Cohen Macaulay then for **every** hsop $f_{1}, \ldots, f_{n}$ we have that $\K[V]^{G}$ is free over $A = \K[f_{1}, \ldots, f_{n}]$

The CM Property is part of commutative algebra and applis to any Noetherian Ring.

> [!theorem|8.8] Hochster-Egens
> In the non-modular case (meaning $\mathrm{char}(\K) \not\mid |G|$) then $\K[V]^{G}$ is Cohen Macaulay.

`\begin{proof}`
Let $R: \K[V] \to \K[V]^{G}$ be the reynolds operator. This is a homomorphism of Modules over $A = \K[f_{1}, \ldots, f_{n}]$. Then
$\K[V] = \K[V]^{G} \oplus \ker(R)$
We know by out previous examples that $\K[V]$ is CM. Let $g_{1}, \ldots, g_{m}, h_{1}, \ldots, h_{l}$ where $g_{i}$ are minimal secondary invariants and the $h_{i}$ are minimal generators of $\ker(R)$ as $A$-Module. Together they minimally generate $\K[V]$ as $A$-Module, meaning they are linearly independent since $\K[V]$ is CM. This means that $g_{1}, \ldots, g_{m}$ $A$-linearly independent
`\end{proof}`

> [!theorem|8.9] Hochster-Roberts
> If $G$ is a linearly reductive group, then $\K[V]^{G}$ is Cohen-Macaulay.

`\begin{proof}`
No Proof
`\end{proof}`

> [!remark|\*]
> If $G$ is reductive but not linearly reductive then there exists a $G$-Module $V$ such that $\K[V]^{G}$ is not Cohe-Macaulay. Meaning the property characterises linearly reductive groups. (Kemper, 2000)
