Let $G$ be finite of infinite and denote a $G$-Module $V$ with $\K[V] = \K[x_{1}, \ldots, x_{n}]$ where $n = \dim(V)$.

> [!definition|11.1]
> A subset $S \subset \K[V]^{G}$ is called separating if for all $v, w \in V$ we have that
> $\exists f \in \K[V]^{G}: f(v) \neq f(w) \implies \exists f \in S: f(v) \neq f(w)$

plainly we call a set seperating if it has the same separation power as the entire invariant set.

> [!remark|\*]
>
> 1. The definition natually generalises to $G$-varieties but everything we will consider will be $G$-Modules
> 2. For finite $G$ we know that every orbit can be seperated, meaning here a set $S \subset \K[V]^{G}$ is separating if it seperates all $G$-Orbits.
> 3. If $\K[V]^{G} = \K[S]$ then $S$ is always seperating, since any invariant can be written as a polynomial in elements of $S$. Meaning if all elements of $S$ agree on two points than any invariant agrees on two points, meaning “generating implies seperating” or alternatively “seperating is a weakening of generating”

> [!example|\*]
> Let $\zeta \in \K$ be a primitive $k$-th root of unity, $G = \left< \begin{pmatrix} \zeta  & 0 \\ 0  & \zeta\end{pmatrix} \right> \cong \Z_{k}$. From the first exercise we know that $\K[V] = \K[x, y]$ and that
> $f_{i} = x^{i} y^{k -i}$
> for $i = 0, \ldots, k$. We also know that $\K[V]^{G} = \K[f_{0}, \ldots, f_{k}]$ minimally
> We know claim that $S = \set{f_{0}, f_{1}, f_{k}}$ is separating. This is true due to the formula
> $f_{i} = \frac{f_{1}^{i}}{f_{0}^{i-1}}$
> Now let $f_{i}(v) = f_{i}(w)$ for $i = 0, 1, k$. Then we get cases
> 4\. $f_{k}(v) \neq 0 \implies f_{i}(v) = f_{i}(w)$ for $i = 1, \ldots, k-1$
> 5\. $f_{0}(v) = 0 = f_{0}(w) \implies 0 = f_{0}(v) = v_{y}^{k}$ which means that $f_{i}(v) = 0 = f_{i}(w)$ for $i < k$
> We can see a similar thing in Exercise 32.

In general it is useful to note that here the set of generating invariants is drastically smaller than the usual generators, which might be practical. Another hope one can have is that the non-modular case doesn’t break as much when considering seperating invariants.

We know a similar case from Exercise 5 which we will repeat here

> [!theorem|11.3]
> Let $|G| < \infty$ with non-variables $t, y$ and form
> $F(t,y) = \prod_{\sigma \in G} \left( y - \sum\limits_{i = 1}^{n} \sigma(x_{i}) t^{i-1}\right) \in \left(\K[V]\right)[s, t]$
> Then the coefficients of $F$ are separating invariants.

`\begin{proof}`
Wit $G$ fixing $t$ and $y$ we can let $G$ act on $F$ and check if it even makes sense to consider the coefficients invariants. We get that $F(t, y) \in \K[V][t, y]^{G} = \K[V]^{G}[t, y]$

Now let $v, w \in V$ such that all coefficients fo $F(t, y)$ agree on $v$ and $w$. This would mean that evaluation is equal of $F$, thus
$\prod_{\sigma \in G} \left( y - \sum\limits_{i = 1}^{n} \sigma(x_{i})(v) t^{i-1}\right) = \prod_{\sigma \in G} \left( y - \sum\limits_{i = 1}^{n} \sigma(x_{i})(w) t^{i-1}\right)$

this is an identity of polynomials in $\K(x_{1}, \ldots, x_{n}, t)$ in which each side is represented by its linear factors. This means that there exists a $\sigma \in G$ such that
$\sum\limits_{i = 1}^{n} x_{i}(v) t^{i - 1} = \sum\limits_{i = 1}^{n} \sigma(x_{i})(v) t^{i - 1}$
since on the left we can choose the identity and know that a right factor must correspond to it. consider this second equation also as a polynomial in $\K[x_{1}, \ldots, x_{n}](t)$ meaning that $x_{i}(v) = \sigma(x_{i})(w) = x_{i}(\sigma^{-1}(w))$. Since the $x_{i}$ are the coordinate function we know that as vectors
$v = \sigma^{-1}(w) \implies G(v) = G(w)$
`\end{proof}`

> [!corollary|11.4] Noether's Bound
> If $|G| < \infty$ there are homogeneous separating invariants of degree $\leq |G|$. We write $\beta_{sep}(\K[V]^{G}) \leq |G|$

`\begin{proof}`
Set $\deg(g) = 1, \deg(t) = 0$ then the function $F(t, y)$ is homogeneous of degree $|G|$
`\end{proof}`

If $|G| = \infty$ then $\K[V]^{G}$ might not be finitely generated, but this might be different for separating invariants.

> [!theorem|11.5]
> There is always a finite separating set $S \subset \K[V]^{G}$ even if $G$ is infinite and $\K[V]^{G}$ not finitely generated.

`\begin{proof}`
Take new varaibles $y_{1}, \ldots, y_{n}$. Let $\Delta f := f(\underline{x}) - f(\underline{y})$ and consider the ideal
$I = \left(\Delta f \midline f \in \K[V]^{G}\right) \subset \K[\underline{x}, \underline{y}]$
by Hilberts Basis Theorem (basically saying that our ring is noetherian) there exists finitely many $f_{1}, \ldots, f_{k} \in \K[V]^{G}$ such that
$I = (\Delta f_{1}, \ldots, \Delta f_{k})$
Now the claim is down to prove that $S = \set{f_{1}, \ldots, f_{k}}$ is a separating set.

To this end let $v, w \in V$ such that there exists $f \in \K[V]^{G}$ with $f(v) \neq f(w)$. Since $\Delta f \in I$ we can write
$\Delta f = \sum\limits_{i = 1}^{k} g_{i}(\underline{x}, \underline{y}) \Delta f_{i}$
We then get
$0 \neq f(v) - f(w) = \Delta f(v, w) = \sum\limits_{i = 1}^{k} g_{i}(v, w) (f_{i}(v) - f_{i}(w))$
this means that there exists some $i$ such that $f_{i}(v) \neq f_{i}(w)$
`\end{proof}`

> [!remark|\*]
> There is no algorithm know  to compute finitely many separating invaraints for $G$ non-reductive (the reductive case was done by Kemper).

> [!theorem|11.6]
> There are at most $2n + 1$ separating invariants for $n = \dim(V)$ assume $\K$ to be infinite.

`\begin{proof}`
By the previous theorem we know that there are finitely many separating invariants $f_{1}, \ldots, f_{k} \in \K[V]^{G}$. Assume $k > 2n + 1$ and note that we can wittle this down.

Take new variables $y_{1}, \ldots, y_{n}, t$ set $g_{i} = t(f_{i}(\underline{x}) - f_{i}(y)) \in \K[\underline{x}, \underline{y}, t]$ and we know that the transcendence degree is $2n + 1$ over $\K$, meaning there exists some $0 \neq H \in K[x_{1}, \ldots, x_{k}]$ in $k$ variables such that $H(g_{1}, \ldots, g_{k}) = 0$

From $\K$ being infinite we can find $\alpha_{1}, \ldots, \alpha_{k} \in \K$ such that $H(\alpha_{1}, \ldots, \alpha_{k}) \neq 0$ and $\alpha_{1 } \neq 0$

Now set $\tilde{f_{i}} = \alpha_{1} f_{i} - \alpha_{i} f_{1} \in \K[V]^{G}$ with $i = 2, \ldots k-1$ and claim that these are seperating. To show this assume that they are not seperating, meaning we assume there exist $v, w \in V$ suchthat $\tilde{f_{i}}(v) = \tilde{f_{i}}(w)$ but there exists $i$ such that $f_{i}(v) \neq f(i)(w)$

We get that
$\tilde{f_{i}}(v) = \tilde{f_{i}}(w) \implies \alpha_{1}(f_{i}(v) - f_{i}(w)) = \alpha_{i}(f_{1}(v) - f_{1}(w))$
Since $\alpha_{1} \neq 0$ we get from this that $f_{1}(v) \neq f_{1}(w)$.

Now set $\eta = \frac{\alpha_{1}}{f_{1}(v) - f_{1}(w)}$ and consider the map $\phi: \K[\underline{x}, \underline{y}, t] \to \K, g \mapsto g(v, w, \eta)$. Applying this to the $g_{i}$ we get
$\phi(g_{i}) = \eta(f_{i}(v) - f_{i}(w)) = \alpha_{i}$
from this it follows that
$H(\alpha_{1}, \ldots, \alpha_{k}) = H(\phi(g_{1}), \ldots, \phi(g_{k})) = \phi(H(g_{1}, \ldots, g_{k})) = 0$
where the second to last step was given by $\phi$ being an algebra homomorphism.
`\end{proof}`

> [!remark|\*]
> The proof of the previous theorem is constructive. This means that given a number of separating invariants we can whittle it down to less than $2n + 1$. The only draw back is that even if starting with homogenous invariants we dont end up with homogeneous ones.

> [!remark|\*] Oddities of Separating Invariants
>
> 1. Given a minimal set of separating invariants it does not need to have minimal size, even when restricting to homogeneous separating invariants.
> 2. Separating Invariants may depend on the ground field $\K$
