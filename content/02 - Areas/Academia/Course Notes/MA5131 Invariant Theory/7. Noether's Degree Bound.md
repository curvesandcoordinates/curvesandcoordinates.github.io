Form now on note that in most cases $G$ will be a finite group. This means that a $G$ module $V$ has a the action given by
$G \to GL(V)$
meaning we forget mostly the algebraic nature of this construction as that would overload.

$\K$ is still a field but now we dont necessarily require that $\K = \bar{\K}$. This means that if $|\K| < \infty$ we cannot identify polynomials and polynomial function (standard example is $x \cong x^{2}$ over $\mathbb{F}_{2}$. $G$ acts on the dual space $V^{*}$ by $\sigma f = f \circ \sigma^{-1}$. Choosing a basis $x_{1}, \ldots, x_{n}$ of $V^{*}$ and write
$\K[V] = \K[x_{1}, \ldots, x_{n}]$
More abstractly we can define $\K[V] = \mathrm{Sym}(V^{*})$ as the symmetric algebra of the dual. We can now extend the action to $\K[V]$ by algebra automorphism (multiplicatively).

In this case we can now build up the same theory as before.

> [!theorem|0] Emmy Noether
> Let $G$ be a finite group acting on a finitely generated $\K$-Algebra $A$. Then $A^{G}$ is finitely generated.

`\begin{proof}`
Write $A = \K[a_{1}, \ldots, a_{n}]$, then for $i \set{1, \ldots, n}$  we form the polynomial
$f_{i}(x) = \prod_{\sigma \in G} (x - \sigma(a_{i})) \in A[x]$
This is in fact a polynoial that is invariant meaning in fact $f_{i} \in A^{G}$. They are monic and $\deg f = |G|$ and crusially $f_{i}(a_{i}) = 0$.
Let $B \subset A^{G}$ be the subalgebra generated by all coefficients of all $f_{i}$, meaning $B$ is finitely generated and thus noetherian.
We know that $A$ is generated as a $B$-Module by
$\set{\prod_{i = 1}^{n}a_{i}^{e_{i}} \midline 0 \leq e_{i} < |G|}$
since $f_{i}(a_{i}) = 0$ we know that that polynomial has highest degree coefficient $a_{i}^{|G|}$and $a_{i}^{|G|}$ is a $B$-linear combination of the $a_{i}^{l}$ with $0 \leq l \leq |G|$.

Therefore $A$ is a noetherian $B$-Module. Since $A^{G}$ is a submodule we know that this must be finitely generated as $B$-Module, meaning that
$A^{G} = \sum\limits_{i} Bg_{i} = B[g_{1}, \ldots, g_{m}]$
`\end{proof}`
Note that this statement is also true if $\K$ is simply a noetherian ring, this is a more general case though that we dont necessarily consider.

Since the previous proof is non-constructive we would like to get a handle on the actual finite generation of our invariant ring. For this we will need to consider a special case of the above theorem. Consider $\K[V]^{G}$ a graded algebra, then any generating set can be assumed to be homogeneous without adding to the number of generators (see graded Nakayama for this). We also saw in corollary 5.4 that all minimal generating sets the same number of elements and the same degrees.

We can now define a number uniquely, namely
$\beta(\K[V]^{G}) = \min \set{k \in \N \midline \K[V]^{G} \text{ is generated by homogeneous invariants of degree } k}$
Due to what we discussed earlier we can also write
$\beta(\K[V]^{G}) = \max \set{\deg(f_{i}) \midline f_{1}, \ldots, f_{m}\text{ minimal homogeneous set of generators}}$

This number carries important information. Since if we know an upper bound for $\beta(\K[V]^{G}) \leq k$ then $\K[V]^{G}$ can be computed as follows: Get Bases $B_{d}$ for $\K[V]^{G}_{d}$ for $d = 1, \ldots, k$ then $\bigcup_{d = 1}^{k} B_{d}$ generates $\K[V]^{G}$.

Meaning that the only remaining question is now how to obtain $B_{d}$. Given our group is finite $G$ we can consider its group generators $\set{\sigma_{1}, \ldots, \sigma_{r}}$. Then $\K[V]^{G}_{d}$ is the kernel of the linear map
$\K[V]_{d} \to \K[V]_{d}^{r}, \quad f \mapsto \begin{pmatrix}\sigma_{1}(f) - f \\ \vdots \\ \sigma_{r}(f) - f\end{pmatrix}$
which we can simply solve to obtain the basis of $\K[V]_{d}^{G}$

> [!theorem|7.1] Noether Bound
> Given that $\mathrm{char}(\K) \nmid |G|$ (for example $\mathrm{char}(K) = 0$), meaning we consider the non-modular case, we have that
> $\beta(\K[V]^{G}) \leq |G|$

For this proof we require a technical lemma

> [!lemma|7.2]
> Let $G$ be a finite group acting on a Ring $R$ and let $J \subset R$ be a $G$-Stable ideal. Suppose $|G| \in R^{\times}$ (regarding an integer as an element of a Ring), then
> $J^{|G|} \subset (J^{G})_{R}$
> meaning the $|G|$-th ideal power is contained in the ideal generated by $J \cap R^{G}$

`\begin{proof}`
We need to show that products of $|G|$ elements of $J$ are in $(J^{G})_{R}$. Let $f_{\sigma}$ for $\sigma \in G$ be elements of $J$ by merely indexing. We have for any $\tau \in G$ the following.
$\prod_{\sigma \in G}(\tau \sigma(f_{\sigma}) - f_{\sigma}) = 0$
since $\tau = \sigma^{-1}$ gives us a zero element. Expanding the product gives us
$\sum\limits_{M \in \mathcal{P}(G)} (-1)^{|G \setminus M|}\left( \prod_{\sigma \in M} \tau(\sigma(f_{\sigma}))  \right)\left( \prod_{\sigma \in G \setminus M} f_{\sigma} \right) = 0$
Summing this over all $\tau \in G$

$$$\begin{align*}
0 &= \sum\limits_{M \in \mathcal{P}(G)} (-1)^{|G \setminus M|} \left( \prod_{\sigma \in G \setminus M} f_{\sigma} \right)\sum_{\tau \in G} \left( \prod_{\sigma \in M} \tau(\sigma(f_{\sigma}))  \right) \\
&= \sum\limits_{M \in \mathcal{P}(G)} (-1)^{|G \setminus M|} \left( \prod_{\sigma \in G \setminus M} f_{\sigma} \right)\sum_{\tau \in G} \tau\left( \prod_{\sigma \in M} \sigma(f_{\sigma})  \right)
\end{align*}$$

Consider now the summand for $M = \emptyset$ 
$$(-1)^{|G|} \left( \prod_{\sigma \in G} f \sigma \right) |G|$$
Summand for $M \neq \emptyset$
$$\pm \sum\limits_{\tau \in G} \tau \left(\prod_{\sigma \in M} \sigma(f_{\sigma})\right) \left(\prod_{\sigma \in G \setminus M} f_{\sigma}\right)$$
now since $\prod_{\sigma \in M} \sigma(f_{\sigma}) \in J$ we know that the sum must be in $J^{G}$ and $\prod_{\sigma \in G \setminus M} f_{\sigma} \in R$ giving us that the entire thing is in $(J^{G})_{R}$

From this we obtain that
$$|G| \cdot \prod_{\sigma \in G} f_{\sigma} \subset (J^{G})_{R} \implies \text{claim}$$
since $|G| \in R^{\times}$.
`\end{proof}`

Proving the theorem we get

`\begin{proof}`
Apply the Lemma to $R = \K[V]$ and $J = \K[V]_{+}$ giving us that $(J^{G})_{R} = H$ the hilbert ideal. On the left side we have that since $J = (x_{1}, \ldots, x_{n})$ meaning $J^{|G|} = \oplus_{d = |G|}^{\infty} \K[V]_{d} = \K[V]_{\geq |G|}$ meaning the lemma gives us
$$\K[V]_{\geq |G|} \subset H$$

Let $t \in \K[x_{1}, \ldots, x_{n}]$ a monomial of $\deg(t) \geq |G|$, meaning we can write it as
$$t = t_{0} \cdot t'$$
with $\deg(t_{0}) = |G|$ and $t'$ monomial. From our lemma we know that $t_{0} \in H'$ where
$$H' = (H)_{R} \subset H$$
also note that $t \in H'$, meaning $\K[V]_{\geq |G|}^{G}  \subset H'$ and by the definition of $H'$
$$\K[V]_{d}^{G} \subset H'$$ for  $0 < d \leq |G|$. Meaning $\K[V]_{+}^{G} \subset H' \implies H \subset H' \subset H \implies H = H'$. giving us that $H$ is generated in degree $\leq |G|$. By Theorem 5.5 with $G$ linearly reductive which it is for finite $G$ in non-modular case, we get
$$\beta(\K[V]^{G}) \leq |G|$$
`\end{proof}`

> [!remark|*] Historical Context
> Some historical context for this theorem. This theorem was proved by Emmy Noether in 1916 for $\mathrm{char}(\K) = 0$ or $\mathrm{char}(K) > |G|$. The case $\mathrm{char}(\K) < |G|$ became known as the Noether Gap whcih was closed in 2000 independently by Fleischmann and Fogarty. The proof presented here was simplified by Benson, Derksen and Kemper.

> [!example|*]
> Consider $G = < \xi_{n} > \subset GL_{1}(\K)$ where $\xi_{n}$ is a primitive root of unity. $\K[V] = \K[x]$ and our group acts as
> $$\sigma(x) = \xi_{n}^{-1} x$$
> It turns out that $\K[x]^{G} = \K[x^{n}]$ giving us
> $$\beta(\K[x]^{G}) = n$$

> [!theorem|7.3] Lower Bound for the Beta Number
> Let $\K = \mathbb{F}_{p}$ with $p \mid |G|$ and $V$ a faithful $G$-Module then
> $$\beta(\K[V^m]^G) \geq \frac{m}{\dim(V)-1} \to \infty$$

`\begin{proof}`
We set $\mathrm{ord}(\sigma) = p$ ad $R = \K[V^{m}] = \K[X_{ij} \mid i = 1, \ldots, m, j = 1, \ldots, n]$ and our $G$ action is considered on $j$-indices

> [!lemma|*]
> Let $t = \prod_{i = 1}^m X_{i, n}^{e_{i}}$ monomial that occurs in an invariant from $R^{\sigma}$ then $p \mid e_{i}$ for all $i$

`\begin{proof}`
Proven before
`\end{proof}`

Consider the function 
$$f = \sum\limits_{\alpha_{1}, \ldots, \alpha_{n} \in \K} \left(\prod_{i=1}^{m} \left(\alpha_{1} X_{i, 1} + \ldots + \alpha_{n} X_{i, n}\right)^{p-1}\right)$$
then note that $f \in R^{\mathrm{GL_{n}(\mathbb{F}_{p})}} \subset R^{G}$.

Now set $t := \prod_{i=1}^{n-1} X_{i,i}^{p-1} \prod_{i = n}^{m} X_{i, n}^{p-1}$, then the coefficient of $t$ in $f$ is
$$\sum\limits_{\alpha_{1}, \ldots, \alpha_{n} \in \mathbb{F}_{p}} \left(\prod_{i = 1}^{n-1} \alpha_{i}^{p-1}\right) \left(\prod_{i = 1}^{m} \alpha_{i}^{p-1}\right)$$
by little fermat we know that $\alpha_{i}^{p-1} = 1$ for $\alpha_{i} \neq 0$ thus the coefficient simiplifies to
$$(p-1)^{n} \neq 0$$
in $\mathbb{F}_{p}$.

Now we want to get at the lower bound. For this we need to prove that given some generators one of them has atleast degree $\frac{m}{\dim(V) - 1}$. To this end let $R^{G} = \K[f_{1}, \ldots, f_{S}]$ with $f_{i}$ homogeneous and positive degree. We know that $f \in R^{G}$, meaning it can be written as linear combination of product of $f_{i}$. The monomial $t$ occurs in $f$ thus is has to also be a product of $f_{i}$, as $f$ is a linear combination of products. Even more it can be written as
$$t = \prod_{i = 1}^{r} t_{i}$$
with $t_{i}$ a monomial occuring in some $f_{j_{i}}$ with $j_{i} \in \set{1, \ldots, S}$. Now we set $d_{i} = \deg(f_{j_{i}}) = \deg(t_{1}) > 0$. We now only need to show that there exists $k$ such that
$$d_{k} \geq \frac{m}{n -1}$$
We have that $t_{i} \mid t$ meaning every exponend of an $X_{j,k}$ in $t_{i}$ is $\leq p-1$. By applying the lemma we know that the monomials $t_{i}$ are never of the form of the lemma as otherwise $t_{i} = 1$. Thus we know that $t_{i}$ involves a variable $X_{j,k}$ with $k < n$. Write 
$$\mathrm{deg'}\left( \prod_{j = 1}^{m} \prod_{k = 1}^{n} X_{j,k}^{e_{j, k}} \right) = \sum\limits_{j=1}^{m} \sum\limits_{k = 1}^{n-1} e_{j,k}$$
using this alternative “degree” (which forgets the $X_{j, n}$) we get that our earlier statement amounts to
$$\mathrm{deg'}(t_{i}) \geq 1$$
Assume that for all $k = 1, \ldots, r$ we have for $d_{i}' = \mathrm{deg'}(t_{i})$
$$d_{k}^{'} \sum\limits_{i = 1}^{r} \mathrm{deg}(t_{i}) > d_{k} \sum\limits_{i = 1}^{r} d_{i}^{'}$$
summing up gives a contradiction since summing gives us equality. Since the assumption is false there exists a $k$ such that
$$d_{k}^{'} \sum\limits_{i = 1}^{r} \mathrm{deg}(t_{i}) \leq d_{k} \sum\limits_{i = 1}^{r} d_{i}^{'}$$
noting that $\deg(t) = \sum\limits_{i = 1}^{r} \deg(t_{i})$ and since we can control this we know that $\deg(t) = m (p-1)$. On the other side we know that $\mathrm{deg'}(t) = \sum\limits_{i = 1}^{r} d_{i}'$ which we know is given by $(n-1)(p-1)$. Pluggin all this in gives us
$$d_{k}' m(p-1) \leq d_{k} (n-1)(p-1)$$
Finally using the fact that $d_{k}' \geq 1$ we get
$$d_{k} \geq d_{k}' \frac{m}{n-1} \geq \frac{m}{n-1}$$


`\end{proof}`

This statement tells us that there is not upper degree bound that only depends on $G$. It always has to depend in some way on the representation. This is also true if $G$ is a linear algebraic group and infinite (due to Bryant, Derksen and Kemper 2004 / 5)
