When viewing [[Signal Analysis|Signals]] with a specific discrete periodic structure we can consider them as maps $f \in \C^{G}$ where $G$ is some abelian group. To better understand these maps we can use the most natural operation in harmonic analysis, which is the [[Convolution on Finite Function Spaces|convolution operator]] on the function space.

Since we want to decribe the nature by which signals might relate to each other we want to use convolution to define an operator on $\C^{G}$ for this consider the following construction

> [!definition|\*] Convolution Operator Generated by an Element
> Let $G$ be a finite abelian ground and $h \in \C^{G}$ a signal. We can define the convolution generated by $h$ as
> $C_{h}: \C^{G} \to \C^{G}, \quad C_{h}f(x) = (f \ast h)(x) = \sum\limits_{y \in G} f(y) h(x-y)$
> We call the set of generated convolution operators $\mathcal{C}_{G} = \set{C_{h} \mid h \in \C^{G}}$

It is important to note that the set of generated convolution operators by construction plays well with the operation of convolution

> [!proposition|\*] Generated Convolutions form an Algebra
> Given elements $f, g \in \C^{G}$ and $\alpha \in \C$ we have the following properties for the generated convolution operators
>
> 1. Additivity: $C_{f + g} = C_{f} + C_{h}$
> 2. Scalar Multiplicativity: $C_{\alpha f} = \alpha C_{h} $
> 3. Convolution multiplication: $C_{f \ast h} = C_{f} C_{h}$

^f98ed9

`\begin{proof}`
The first two properties are given by the [[Convolution on Finite Function Spaces#^4955ce| basic properties of convolution]]. The third can be explicitly calculated for some $T \in \C^{G}$
$C_{f * h} T(x) = (T * f * h)(x) =((T * h) * f) (x) = C_{f}(T * h) (x) = C_{f} C_{h}T(x)$
where we use the commutativity of the convolution on $\C^{G}$ for a finite abelian group $G$
`\end{proof}`

The immeate consequence of this is that we can construct an algebra from this structure

> [!definition|\*] Algebra of Generated Convolution Operators
> The set$\mathcal{C}_{G} = \set{C_{h} \mid h \in \C^{G}}$
> togehter with pointwise addition and multipcation given by the convolution form an algebra.

Now this algebra contains a lot of information on how different signals can interact and what signals exist. We have already seen this algebra in a different form though, which will be our first insight

> [!proposition|\*] Generated Convolution Operator Algebra is isomorphic to group Algebra
> For a finite abelian group $G$ we have an algebra isomorphism
> $\mathcal{C}_{G} \cong \mathcal{A}(G)$
> where $\mathcal{A}(G) = (L^{1}(G), \ast)$ is [[The Group Algebra|the group algebra]] of $G$

`\begin{proof}`
The natural embedding we can construct here is a map
$\phi: \mathcal{A}(G) \to \mathcal{C}_{G}, \quad f \mapsto C_{f}$
this is trivially an algebra homomorphism. Its naturally injective and the surjectivity amounts to showing that $\C^{G} = L^{1}(G)$ for a finite abelian group which is true by definition since
$f \in L^{1}(G) \iff \sum_{x \in G} f(x) < \infty$
is always given for any $f \in \C^{G}$. Thus we have an algebra isomorphism.
`\end{proof}`

Another way we can decribe the elements of the generated convolution operators that gives us even more insight into its structure is given by the following theorem

> [!theorem|\*] Generated Convolution Operator Equivalences
> Let $A \in End(\C^{G})$ be an operator and $G$ a finite abelian group. Then the following are equivalent:
>
> 1. $A$ is translation invariant (or $G$-Invariant)
> 2. $A \in \mathcal{C}_{G}$
> 3. Every character $\chi \in \widehat{G} \subset \C^{G}$ is an eigenverctor of $A$ with Eigenvalue $\widehat{h}(\chi)$

`\begin{proof}`
$\underline{1 \implies 2}$
Let $A \in End(\C^{G})$ be an operator with kernel $a \in \C^{G \times G}$. Since by assumtion $A$ is $G$-Invariant we see that
$a(x, y) = a(x - y, y- y)= a(x-y, 0)$
Take $h(x) = a(x, 0)$ with $x \in G$ then note that for any map $f \in \C^G$
$(f \ast h)(x) = \sum\limits_{y \in G} f(y) h(x-y) = \sum\limits_{y \in G} f(y) a(x-y, 0) = \sum\limits_{y \in G} a(x, y) f(y) = A f(x)$
thus giving us
$A = C_{h} \in \mathcal{C}_{G}$
$\underline{2 \implies 3}$
Let $A = C_{h}$ for some $h \in \C^G$ and let $\chi \in \widehat{G}$. Then we get

$A \chi(x) = C_{h} \chi(x) = (\chi * h)(x) = (h * \chi)(x) = \sum\limits_{y \in G} h(y) \chi(x - y) = \sum\limits_{y \in G} h(y) \chi(x) \overline{\chi(y)} = \chi(x) \widehat{h}(\chi)$
Meaning we have shown that $\chi \in \widehat{G}$ is an Eigenvector of $A = C_{h}$ with the Eigenvalue $\widehat{h}(\chi)$.

$\underline{3 \implies 1}$
Now suppose $\chi \in \widehat{G}$ is an eigenvector of $A$ with eigenvalue $\lambda_{\chi}\in \C$.  We then have that since this is an eigenvector that
$A \chi = \lambda_{\chi} \chi$
Since via the inversion formula we know that any function $f \in \C^{G}$ can be written as a linear combination of characters with fourier coefficients thus we have for any function expressed as
$f(x) = \frac{1}{|G|} \sum\limits_{\chi \in \hat G} \hat f(\chi) \chi(x)$
that
$Af(y) = \frac{1}{|G|} \sum\limits_{\chi \in \widehat{G}} \lambda_{\overline\chi} \widehat{f}(\chi) \overline{\chi(y)}$
Given the translation operator we can easily calculate that
$\widehat{T_{x} f}(\chi) = \chi(x) \widehat{f}(\chi)$

This gives us that
$A T_{x} f(y) = \frac{1}{|G|} \sum\limits_{\chi \in \widehat{G}} \lambda_{\chi} \widehat{T_{x} f}(\chi) \chi(y) = \frac{1}{|G|} \sum\limits_{\chi \in \widehat{G}} \lambda_{\chi}\chi(x) \widehat{f}(\chi) \chi(y)$
Now since we can calculate
$T_{x} Af(y) = T_{x} \left( \frac{1}{|G|} \sum\limits_{\chi \in \widehat{G}} \lambda_{\overline\chi} \widehat{f}(\chi) \chi(y) \right) = \frac{1}{|G|} \sum\limits_{\chi \in \widehat{G}} \lambda_{\chi} \widehat{f}(\chi) \chi(x + y) = \frac{1}{|G|} \sum\limits_{\chi \in \widehat{G}} \lambda_{\chi} \widehat{f}(\chi) \chi(x) \chi(y) = A T_{x} f(y)$
This means that $A$ is translation invariant since
$T_{x} A = A T_{x}$
`\end{proof}`

From this we can take that all translation-invariant operators on $\C^G$ are the convolution operators. This makes the convolution operators very special as operators since they act uniformly across the whole group $G$. We can also see that a the convolution of signals can be seen to be a sort of [[Signal Filter|signal filter]] which means that in whole we are saying that all operations on functions that affect the group uniformly are filters.

Lets gather some simple consequences of this proposition which tells us more about these important operators.

> [!corollary|\*] Spectrum of Convolution Operators
> Given a finite abelian group $G$ every $C_{h} \in \mathcal{C}_{G}$ for some $h \in \C^G$ is diagonalizable with
> $\spec(C_{h}) = \set{\hat h (\chi) \midline \chi \in \hat G}$

`\begin{proof}`
By the inversion formula for the [[Discrete Fourier Transform|DFT]] we know that $\widehat{G}$  is a basis for $L^1 = \C^G$. If we use this we know that for any $C_{h}$ we have that
$C_{h} \chi = \lambda_{\chi} \chi$
and from the previous proof we already know $\lambda_{\chi} = \widehat{h}(\chi)$

Given $\dim \C^G = |G| = | \widehat{G} |$ we can diagonalize $C_{h}$ by expressing it in the basis $\widehat{G}$. This gives us a diagonal form where the diagonal entries are given by the eigenvalues
$\set{\widehat{h}(\chi) \midline \chi \in \widehat{G}}$
`\end{proof}`

> [!corollary|\*] Trace of Convolution Operators
> Given a finite abelian group $G$ consider for some $h \in \C^G$ the convolution transformation $C_{h} \in \mathcal{C}_{G}$. Then we have that
> $\tr(C_{h}) = \sum\limits_{\chi \in \widehat{G}} \widehat{h} (\chi) = |G| h(0)$
> where $0 \in G$ is the identity

`\begin{proof}`
Via considering the basis $\widehat{G}$ we can again diagonalize the matrix for $C_{h}$ and obtain that the diagonal of the matrix is given by $\set{\widehat{h}(\chi) \midline \chi \in \widehat{G}}$ . From this we see that
$\tr(C_{h}) = \sum\limits_{\chi \in \widehat{G}} \widehat{h}(\chi)$
Given that by the inversion formula we get
$h(x) = \frac{1}{|G|} \sum\limits_{\chi \in \widehat{G}} \widehat{h}(\chi) \chi(x) \implies \sum\limits_{\chi \in \widehat{G}} \widehat{h}(\chi) = |G| h(0)$
this gives us the statement
`\end{proof}`
