A [[Groups|group]] can have arbitrary structure but we can consider what structure a group has if we generate it from a set. This means given a set of elements (with an implied multiplication map) we can see what the smallest possible group is containing this set. If the set we started with was group already this turns out to be a subgroup (obviously)

> [!definition|\*] Generated Subgroups
> Let $G$ be a group and $X \subset G$ and define
> $\left< X \right> := \set{x_{1}^{k_{1}} x_{2}^{k_{2}} \ldots x_{j}^{k_{j}} \midline x_{i} \in X, k_{i} \in \Z, j \in \N}$
> then we can see that $\left< X \right>$ is a subgroup of $G$ generated by $X$. We also formally define
>
> $$$\begin{align*}
> \left< \emptyset \right> :&= \set{e}\\
> \left< \set{x_{1}, x_{2}, \ldots, x_{n}} \right> :&= \left< x_{1}, x_{2}, \ldots, x_{n} \right>
> \end{align*}$$
> $$$

This definition makes sense and can prove useful. Since we now know in a sense the structure of every element in $\left< X \right>$ as we have determined the set $X$. The intuition as stated before can be summarised by the following proposition.

> [!theorem|\*] Minimality of Generated Subgroupså
> Let $G$ be a group, $X \subset G$ then $\left< X \right>$ is the smallest subgroup which contains $X$

`\begin{proof}`
Assume there exists a subgroup $H \leq G$ with $X \subset H \leq \left< X \right>$ then the following inclusions hold
$X \subset H \leq \left< X \right> \leq G$
Since we have $X \subset H$ we know that for any $x \in X$ we have that $x^{k} \in H$ for any $k \in \N$. Any product of $x^{k}, y^{j}$ etc must also be in $H$. Thus we have that
$\left< X \right> \leq H$
This means that our inclusions reduce to
$X \subset \left< X \right> \leq G$
And by contradiction $\left< X \right>$ is the smallest subgroup containing $X$
`\end{proof}`

We should note that this theorem states a minimality condition which can almost always be thought of as a intersection. Due to this we will also show a different way of defining the generated subgroup which is equivalent but just different:

> [!corollary|\*] Alternative Formulation for Generated Group
> Given a Group $G$ and a set $X \subset G$ we can equivalently define
> $\left< X \right> = \bigcap_{H \leq G, X \subset H} H$

`\begin{proof}`
This is a direct consequence of the previous theorem since the equivalence of groups is mainly given by the minimality property.
`\end{proof}`

In this context of groups and subgroups and generated subgroups we should think about the minimal object. Here the minimal object is simply generating a subgroup by one element $a \in G$. This simply amounts to taking all the possible powers of $a$ and can be thought as a type of building block of groups.

> [!definition|\*] Cyclic Groups
> If $G = \left< a \right>$ then $G$ is called a cyclic group

> [!proposition|\*] Basic Properties of Finite Cyclic Groups
> Let $G = \left< a \right>$ of order $N$ then
> $G = \set{e, a, a^{2}, a^{3}, \ldots, a^{N-1}}$
> and
>
> 1. $N = \min \set{m \in \N \midline a^{m} = e}$
> 2. $a^{m} = e \iff N \mid m$
> 3. Let $i, j, k \in \set{0, 1, \ldots, N-1}$ then $a^{i} a^{j} = a^{k} \iff i + j = k \mod N$

`\begin{proof}`
The definition immeadiately give us that
$\left< a \right> = \set{e, a, a^{2}, a^{3}, \ldots, a^{N-1}}$

1. Assume there exists a $M < N$ such that $a^{M} = e$. We can then trivially identify all $a^{M+j} = a^{j}$ and note that our group takes on the form $\left< a \right> = \set{e, a, a^{2}, a^{3}, \ldots, a^{M-1}}$ but this is a contradiction since now $| \left< a \right>| = M \neq N$
2. Taking any $m \in \N$ with $a^{m}= e$ we can always by the minimality proven in (1) decompose into $e = a^{m} = a^{m' + kN} = a^{m'} (a^{N})^{k} = a^{m'}$with $0 \leq m' < N$ and some $k \in \N$. Now we can see that $m' = 0$ is equivalent to $a^{m} = e$ but also it is apparent that $m' = 0 \iff N \mid m$
3. Given that $a^{i} a^{j} = a^{k} \iff a^{i+j} = a^{k} \iff a^{i+j-k} = e$ we can use the second property to show that $a^{i}a^{j} = a^{k} \iff N \mid i+j-k \iff i+j-k = 0 \mod N$
   `\end{proof}`

We can now work towards a very useful general view of cyclic groups. As you can see from the above description of the elements of a cyclic group $\left< a \right>$ we can construct a intuitive map
$\phi: \set{0, 1, 2, \ldots, N-1} \to \left< a \right>, \quad m \mapsto a^{m}$
We want this map to be a group isomorphism so that we can project the structure of any cyclic group onto the group with the set $\set{0, 1, 2, \ldots, N-1}$. The main way to do this is to first find out what group our source should be, the best choice here is to consider that
$\set{0, 1, 2, \ldots, N-1} = \faktor{\Z}{N \Z} = \Z_{N}$
Using this the map becomes an isomorphism and we can always consider the structure of the integers mod $N$ instead of concerning ourselves with the actual elements of our group (meaning the only information that differentiates cyclic groups is their order). Towards this end we will use the following proposition

> [!proposition|\*] Properties of the Cyclic group $\Z$
> If $H < \Z$ then there exists $N \in \N$ such that
> $H = N \Z = \set{Nk \midline k \in \Z}$
> moreover $N \Z \leq m \Z \iff m \mid N$

`\begin{proof}`

`\end{proof}`

> [!theorem|\*] Every finite Cyclic Group is $\Z_{N}$
> Let $G$ be cyclic group with $|G| = N$ then $G \cong \Z_{N}$

^185844

`\begin{proof}`
By assumption $G = \left< a \right>$ and $|G| = N$ we consider the map $\phi: \Z \to G, k \mapsto a^{k}$. Then since we know the structure of $G$ we know that this map is a surjective homomorphism. Its kernel is trivially given by $\ker \phi = N \Z$ Thus we know that
$G = \im \phi = \faktor{\Z}{\ker \phi} = \faktor{\Z}{N \Z} = \Z_{n}$
`\end{proof}`

This give us that if we $G = \left< a \right>$ with $|G| = n$ then

> [!theorem|\*] Subgroups of Cylic Groups
> Let $G = \left< a \right>$ and $|G| = N$ and $l_{1}, \ldots, l_{k} \in \N$ divisors of $N$. Then
> $U_i = \left< a^{l_{i}} \right>$
> are the only subgroups of $G$. Moreover if
>
> 1. $N = n_{i} l_{i}$ then $|U_{i}| = n_{i}$
> 2. Let $m \in \Z \setminus \set{0}$. If $i \in \set{1, \ldots,k}$ such that $l_{i} = gcd(m, N)$ then $\left< a^{m} \right> = U_{i}$

`\begin{proof}`
By the [[#^185844|characterization of finite cyclic groups]] $G \cong \Z_{N}$ thus the subgroups of $G$ correspond to the subgroups of $\Z_{N}$ thus they correspond to subgroups of $\Z$ that contain $N \Z$.
Hence we know that
$U_i = \phi(l_i \Z)$
are the only subgroups of $G$, where $\phi$ is the isomorphism naturally constructed.

1. If $l_{i} \mid m$ then $a^{m} \in U_{i}$. Thus giving us $< a^{m} > \leq U_{i}$. There are integers $m_{1} , m_{2} \in \Z$ such that $l_i = N m_1 + m m_2$ giving us that $a^{l_{i}} =a^{l_{i}} \left( a^{-N} \right)^{m_{1}} = \left( a^{m} \right)^{m_{1}}$ implying that $U_{i} \leq \left< a^{m} \right>$
2. Using the fact that $gcd(m, N) = l_{i} \implies \exists x, y \in \Z: \quad xm + yN = l_{i}$ we get the simple equality of $U_i = \left< a^{l_{i}} \right> = \left< a^{xm + yN} \right> = \left< a^{xm} (a^{N})^{y} \right> = \left< a^{xm} \right>$
   `\end{proof}`

> [!remark|\*] Being Cyclic is especially Simple
> The direct product of cyclic groups is not necessarily cyclic. A prototype for this is given by comparing $\Z_{2}$ and $G = \Z_{2} \times \Z_{2}$, since $\Z_{2}$ is cyclic but $G$ is not.

> [!proposition|\*] Products of Coprime Finite Cyclic Groups
> Let $r, s \in \N$ with $gcd(r, s) = 1$. If $N = r \cdot s$ then
> $\Z_{N} \cong \Z_{r} \times \Z_{s}$

`\begin{proof}`
To Prove this we construct a map from $\Z_{N}$ to $\Z_{r} \times \Z_{s}$ and prove its an isomorphism. Consider the map
$\phi: \Z_{N} \to \Z_{r} \times \Z_{s}, \quad [a]_{N} \mapsto ([a]_{r}, [a]_{s})$
This map is injective since $\ker \phi = \set{[a]_{N} \in \Z_{N} \midline a = 0 \mod r, a = 0 \mod s} = \set{[0]_{N}}$ and surjective since we can easily see that
for a given tuple $(a, b) \in \Z_{r} \times \Z_{s}$ we can use the fact that
$gcd(r, s) = 1 \implies xr + ys = 1 \implies \begin{cases}ys = 1 \mod r \\ xr = 1 \mod s\end{cases}$
We can now explicitly construct our value $x = a ys + b xr$ then using the equations just proben we get
$\phi([x]_{N}) = (a, b)$

`\end{proof}`

A generalization of this is known as the Chinese Remainder Theorem. It is closely linked to the extended euclidean algorithm.

> [!theorem|\*] Chinese Remainder Theorem
> Let $N = p_{1}^{k_{1}}\cdot \cdots \cdot p_{t}^{k_{t}}$ with $p_{i}$ primes then
> $\Z_N \cong \Z_{{p_1}^{k_{1}}}\times \cdots \times \Z_{{p_t}^{k_t}}$

`\begin{proof}`
Corollary of the previous proposition by generalizing it.
`\end{proof}`

If we limit ourselves to one prime number and simply consider powers of primes we can also create groups with order $p^{k}$ but these arent simply cyclic by the following proposition.

> [!proposition|\*] Products of Cyclic groups of the same Prime order are not Cyclic
> Let $p \in \N$ be prime and $m_{1} \geq m_{2} \geq \ldots m_{t} \geq 0$ integers then
> $G = \Z_{p^{m_{1}}}\times \cdots \times \Z_{p^{m_t}}$
> is not a cyclic group.

`\begin{proof}`
Let $<a_{1}> = \Z_{p^m_{1}}$ then the elements of maximal order is of the form $(a_{1}, a_{2}, \ldots, a_{k})$. This element has order $p^{m_{1}}$ since $m_{1}$ is the biggest. But since $|G| = p^{m_{1} + \cdots m_{k}}$

Let us note that we can generate cyclic groups
$U_{i} = \left< a_{i} \right> = \Z_{p_{i}^{m_{i}}}$
then we know that the element $A = (a_{1}, a_{2}, \ldots, a_{t})$ has maximal order in $G$. This element must have order $p^{m_{1}}$ since this is the biggest power and thus $U_{i}$ has biggest order. But since this element of maximal order has an order
$ord(A) = p^{m_{1}} < p^{m_{1} + m_{2} + \cdots + m_{t}} = |G|$
thus the group is not cyclic since even the element of maximal order has order smaller than $|G|$.
