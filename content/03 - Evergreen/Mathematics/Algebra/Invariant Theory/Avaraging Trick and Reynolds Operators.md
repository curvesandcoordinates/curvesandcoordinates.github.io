In the context of invariant theory and representation theory we define the reynolds operator as a canonical projection of $G$-Module $V$ for some nice group $G$ mapping into the invariants of the modules:
$R: V \to V^{G}, \quad \at{R }{V^{G}} = \mathrm{id}$
this a rather obsure map that we dont give explicitly often. It is very useful though and specifically characterises linear reductivity as:

> [!theorem|\*] Linear Reductivity is equivalent to having Reynolds operators.
> A linear algebraic group $G$ has the following equivalence
> $G \text{ is linearly reductive} \iff \forall V \text{ G-Modules} \exists R:V \to V^{G}, \quad \at{R }{V^{G}} = \mathrm{id}$

which is a nice property giving us that the [[Invariant Ring|invariant ring]] $\K[V]^{G}$ is finitely generated by Hilbert’s Finiteness Theorem.

In the following we will try to find a nice intuition for the Reynolds by starting at a very hands on example and then moving to generalities. We will also attempt to use this example as a way to see why other definitions of linear reductivity exists which are equivalent to the one shown above.

## Symmetric Functions

Consider the simple group $G = S_{2}$. This is simply a “swapping group” since it contains only two elements,
$S_{2} = \set{\mathrm{id}, \sigma}$
where $\sigma: (x, y) \mapsto (y, x)$ is the swap. This is reasonably simple group and in fact it has a nice action on the set $\R[x]$. Namely we can consider the action of the group to be defined as
$\sigma f(x) = f(-x)$
Thus our swap flips the graph of $f$ on the $y$-Axis. We know intuitvely that the set of polynomials left invariant under this are the symmetric polynomials, meaning
$\R[x]^{S_{2}} = \set{f: \R \to \R \midline f(-x) = f(x)}$

### Avaraging Trick:

A nice trick we can do to turn a general function $f: \R \to \R$ is to take the avarage of the function and its flipped version:
$g(x) = \frac{f(x) + f(-x)}{2}$
this function now is obviously symmetric since
$g(-x) = \frac{f(-x) + f(x)}{2} = g(x)$
Formally defining this trick as a map we can see that
$R: \R[x] \to \R[x]^{S_{2}}, \quad R(f)(x) = \frac{f(x) + f(-x)}{2}$
in fact this is the unique reynolds operator in this case, since it is (by proof) unique and we have the property that
$f \in \R[x]^{S_{2}}: R(f)(x) = \frac{f(x) + f(-x)}{2} = \frac{2f(x)}{2} = f(x) \implies R(f) = f$

This map is super useful in this case, since it allows us to symmetrize any function while keeping the already symmetric functions untouched.

### Generalizing

We would like generalize the existence of such a nice map to general settings. For this we can notice that for any finite group $G$ where $G$ acts linearly on $\K[x]$ by
$\sigma f(x) = f(\sigma^{-1} x)$
and the action of $G$ on $\K$ is any suitable one, meaning $\mathrm{char}(K) \nmid |G|$. We can always construct the avarageing trick, namely for any polynomial $f \in \K[x]$ we can construct
$g(x) = \frac{1}{|G|} \sum\limits_{\sigma \in G} \sigma f(x)$
the constructed function is now invariant, since
$(\tau g)(x) = \frac{1}{|G|} \sum\limits_{\sigma \in G}\tau \sigma f(x) = \frac{1}{|G|} \sum\limits_{\eta \in G}\eta f(x) = g(x)$
by substituting $\eta = \tau\sigma$. Which means that we again can construct a map
$R: \K[x] \to \K[x]^{G}, \quad R(f)(x) = \frac{1}{|G|} \sum\limits_{\sigma \in G} \sigma f(x)$
which again is easily checked to be the unique reynolds operator in this situation.

## Linear Reductivity

We thus see that finding this Reynolds operator as an avarage is really easy and canonical in the finite group case. We want this in general so we simply call a group to be well-behaved in some way if you can find this reynolds operator. In this abstraction we have to notice that the choice of polynomial ring and so an was very arbitrary and thus we will want any $G$-Module to have such a reynolds operator. Such a group we call in the end **linearly reductive**.

This definition makes sense and is useful. Now something that we have to keep in mind is that thinking of the reynolds operator as this avarage is super useful. In many proofs and even in the compact group case, we always come up with a form of the reynolds operator that is very similar to that of an avarage.

Note though that the actual definition of linear reductivity is a different one than given here, we mostly define

> [!definition|\*] Linearly Reductive in Representation Theory
> A group $G$ is called linearly reductive if for every $G$-Module $V$ we can find for any submodule $W \subset V$ there exists a complement $U \subset V$ such that
> $V = U \oplus W$

### Linear Reductivity in the Symmetric Functions case:

In the case of symmetric functions we can not only come up with a reynolds operator via the avaraging trick, we can also find a cool property. Namely that we can decompose the space of polynomials into two $G$-Stable subspaces
$\R[x] = \R[x]^{S_{2}} \oplus O$
where $O = \set{f: \R \to \R \midline f(-x) = -f(x)}$ are the odd functions. This decomposition is also characteristic for the well-behavedness of the group $S_{2}$ and also helps us understand the function fully and decompose (or **REDUCE IT**) to its action on two parts.

In a sense this is the other side of the coin for the reynolds operator, since that function is exactly the projection onto the invariants that takes any odd function and symmetrizes it. This defintion of well-behaved groups can be abstracted similarly to above to obtain a more similar view of linear reductivity as we have shown.

## Equivalency of Linear Reductivity and Existence of Reynolds Operators

Lastly we will show the equivalence of these two concepts explicitly, this is done in a more general note as well but fills this picture up.

> [!theorem|\*] Linear Reductivity is equivalent to having Reynolds operators.
> A linear algebraic group $G$ has the following equivalence
> $G \text{ is linearly reductive} \iff \forall V \text{ G-Modules} \exists R:V \to V^{G}, \quad \at{R }{V^{G}} = \mathrm{id}$

`\begin{proof}`
$Left \implies Right$
Let $G$ be linearly reductive and $V$ a $G$-Module. Then we can see that $V^{G}$ is a submodule since it is closed under the $G$-Action. By the linear reductivtiy we can find a $G$-Stable Complement $U$ such that
$V = V^{G} \oplus U$
This has a natural $G$-Stable projection $\pi: V \to V^{G}$. This is then exactly the reynolds operator.

$Right \implies Left$
Let $G$ have a reynolds operator $R$ for every $G$-Modules. Let $V$ be such a $G$-Module, and let $U \subset V$ be a submodule. Then we know that this is a $G$-Stable finite dimensional subvector space and as a vector space it has its canonical complement $W \subset V$ such that
$V = U \oplus W$
We only need to show that $W$ is itsself $G$-Stable. This is done by noting that the decomposition as vector spaces comes with a natural projection $\pi: V \to U$ such that $\at{\pi}{U} = \mathrm{id}_{V}$.

Now we consider another $G$-module, namely $\mathrm{Hom}_{\K}(V, U)$ the linear maps from $V$ to $U$. We let $G$ act on this vector space by
$\sigma f (v) = \sigma(f(\sigma^{-1}(v)))$
Note that this is a good action since invariance under this means that for $f \in \mathrm{Hom}_{\K}(V, U)^{G}$
$f(v) = \sigma f(v) = \sigma(f(\sigma^{-1} v)) \iff \sigma^{-1} f(v) = f(\sigma^{-1} v)$
telling us that any invariance means that the map is a $G$-Morphism. By the assumption we know that there exists a Reynolds operator for this $G$-Module,
$\mathcal{R}: \mathrm{Hom}_{\K}(V, U) \to \mathrm{Hom}_{\K}(V, U)^{G}, \quad \at{\mathcal{R}}{\mathrm{Hom}_{\K}(V, U)^{G}} = \mathrm{Id}$
This operator is a way to make any linear map $V \to U$ into a $G$-homomorphism. Thus we define
$P = \mathcal{R}(\pi)$
We only need to show that $P$ is $G$-Homomorphism that still fixes $U$, so that we may decompose $V$ into the kernel and the image.

For this we consider the restriction map
$\mathrm{res}: \mathrm{Hom}_{\K}(V, U) \to \mathrm{Hom}_{\K}(U, U), \quad f \mapsto \at{f}{U}$
under our action this map is $G$-Equivariant, since for any $u  \in U$
$\mathrm{res}(g \cdot f)(u)= \at{g \circ f \circ g^{-1}}{U}(u) = g \circ (\at{f \circ g^{-1}}{V})(u) =  g \cdot \mathrm{res}(f)(u)$
Now consider the Reynolds operator on $\mathrm{Hom}_{\K}(U, U)$ denoted
$\mathcal{R}_{U}: \mathrm{Hom}_{\K}(U, U) \to \mathrm{Hom}_{\K}(U, U)^{G}$
we then can easily see that due to the $G$- equivariance of $\mathrm{res}$ it commutes with the reynolds operators (this can easily be proven by calculation) and thus
$\at{P}{U} = (\mathrm{res} \circ \mathcal{R})(\pi) = (\mathcal{R}_{U} \circ res) (\pi) = \mathcal{R}_{U}(\at{\pi}{U}) = \mathcal{R}_{U}(\mathrm{id}_{U}) = \mathrm{id_{U}}$
since $\mathrm{id}_{U} \in \mathrm{Hom}_{\K}(U, U)^{G}$.

Thus we have shown that $P$ is a $G$-homomorphism that is a projection, with $\at{P}{U} = \mathrm{id}_{U}$. Thus we can decompose the space $V$ into
$V = \ker P \oplus U$

`\end{proof}`
